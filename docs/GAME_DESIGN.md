# 브릭 크롤 게임 디자인 문서 (현재 구현 기준)

> 용어: 화면에서는 본편 단위를 **층**(1층~5층, 협곡을 내려가는 깊이), 층 안의 칸을 **구역**(1~4번째 구역 + 보스)이라 부른다. 이 문서와 코드의 "세션"(`RUN.s`)·"칸"(`node.r`)은 같은 뜻이다.
> 화면에 쓰는 이름(모듈·커밋·큐·크레딧·트로피·순위표·터미널 등)은 [`docs/GLOSSARY.md`](GLOSSARY.md)가 기준이다. 이 문서는 화면 이름을 쓰고, 필요하면 괄호에 코드 이름(`TREE`·`pts`·`deck`·`coins`·`BADGES`…)을 붙인다.
> 세계관: 중세 판타지(기사·탑·성벽) → 2026-10-28 **디지털 던전**(데이터 벽·버그) → 2026-10-30 이야기 **"마지막 번개"**(릭·리나·OMNIS, 대본 `docs/SCENARIO.md`). 코드 id·저장 키는 그대로 두고 화면 이름만 바꿨다.

## 한 줄 요약
움직이는 조준선에 타이밍을 맞춰 구슬을 쏘고, 내려오는 데이터 벽을 깎아 **천장에 닿게 해야** 위쪽의 버그를 때리는 턴제 벽돌깨기 로그라이크.

## 화면
- 위 110px: 전투(왼쪽 릭, 오른쪽 버그, 체력·공격·방어, 버그의 다음 행동 예고).
  - 버그 공격 예고: 머리 위 붉은 ⚔ + 숫자 = **남은 연속 공격 턴 수**. 매 턴 아래 ⚔ 숫자(공격력)만큼 때리고, 붉은 숫자는 3 → 2 → 1로 줄어든다. 예: ⚔2에 붉은 3이면 3턴 동안 2씩, 총 6.
  - 이유: 예전엔 배율(×2.5) 강공격이 있어 아래 ⚔ 숫자와 실제 피해가 어긋났다. 이제 한 번의 피해는 언제나 아래 ⚔ 숫자 그대로다.
- 아래: 벽돌판. 맨 위 굵은 선 = 천장, 중간 점선 = 오버플로선, 맨 아래 = 발사대.
- DOM: 헤더(세션·칸·이름, 크레딧·턴), 구슬 줄(이번 구슬 초상화 + "조준"/"발사!", 다음 구슬), 칩 칩, 오버레이(터미널·순위표·지도·선택·일시정지).
- 전투 중 화면(2026-10-26 출시 검토): 폰 한 화면에 발사대까지 들어오게 브랜드 띠·조작 힌트를 숨기고, 헤더는 한 줄(위치 "1-5 보스"·"심층부 2-3 정예" + 버그 이름 / 크레딧 그림 + "120 · 3턴" / 일시정지), 구슬 줄 높이 48px, 칩 줄은 한 줄 가로 스크롤. 판 폭은 남은 세로 높이에서 9:17로 정한다(390×844에서 330 → 364px). 긴 위치 표기("1층 · 5번째 구역")는 시작 배너가 보여 준다.
- 글꼴: 화면 제목·지도 층 제목·시작 배너·시작 버튼만 픽셀 한글 Galmuri(동봉, OFL, 22·33px), 나머지는 시스템 글꼴. 작은 크기의 픽셀 글꼴은 가독성이 떨어져 되돌렸다. 선택 카드·트리 설명은 양피지 장식과 글자가 겹치지 않게 안쪽 여백을 넓혔다.
- 터미널(첫 화면, 코드의 메인 `ovMain`): 도트 로고, 구슬 진열, 호출명, 기록 줄, **시작 버튼 하나만 화려하게**(이어할 접속이 있으면 "접속 이어 가기", 없으면 새 접속: 석판 그림·크게·빛 띠·▶ 깜빡임), 심층부 버튼(붉은 테 석판, 잠기면 점선), 보조 버튼(모듈·아카이브, 얇은 테), 순위표 상위 3명, 음악·효과음·테마.
- 오버레이는 위에서부터 쌓고 첫·끝 요소의 auto 여백으로 가운데 정렬한다. `justify-content:center` + 스크롤이면 넘친 위쪽(로고)이 스크롤로도 안 보이는 문제가 있었다.

## 한 턴의 흐름
1. 조준선이 일정 속도로 좌우 왕복(삼각파). 턴마다 시작 위치·방향 무작위. 시작 0.2초는 입력 무시.
   - 가속: 정예는 체력 절반 이하에서 ×1.35(배너 "정예가 날뛴다"), 보스는 페이즈마다 +30%(2페이즈 ×1.3, 최종 보스 3페이즈 ×1.6). 배너 둘째 줄은 둘 다 "조준이 빨라진다"(페이즈 번호 대신 바뀌는 규칙을 말한다). 가속 중에는 발사대 양옆에 붉은 화살표가 깜빡인다.
2. 탭/Space로 발사. 이번 구슬 하나를 쏜다(분열 구슬은 3갈래).
3. 구슬이 벽돌을 부숴도 **튕긴다**(송곳 구슬만 관통). 천장에 닿으면 버그 타격(구슬당 최대 3회). **피해 = 릭의 공격력(⚔) + 구슬 위력(`ORB_BONUS`)** (+ 연쇄) → 코어 모듈(모듈 갈래 끝, 코드의 핵심 노드) 배율. 구슬 줄에 `⚔2 + 1 = 3`처럼 식으로 뜬다(⚔ 벽돌을 깨면 왼쪽, 센 구슬이면 가운데 숫자가 오른다).
4. 구슬이 바닥에 닿으면 끝. 처음 돌아온 구슬 위치가 다음 발사 위치.
5. 버그 독 틱 → 버그 행동 → (2턴마다) 데이터 벽 한 줄 하강 + 새 줄 → 오버플로선 넘은 벽돌은 릭에게 1개당 2 피해 → 릭 독 틱.

## 피해 규칙
- 방어도 = 체력 앞의 보호막. 피해를 먼저 흡수하고 흡수한 만큼 깎인다. 릭·버그 동일.
- 독 = 스택. 턴마다 스택만큼 피해(방어도 무시) 후 1 감소. 체력바 끝이 다음 틱 피해만큼 붉게 표시.
- 공격력·방어도는 전투마다 초기화(공격 1(+최적화), 방어 0, 하드 케이스·방화벽 규칙만 시작 방어도). 체력은 접속 내내 이어진다(최대 24에서 시작, 보스를 잡을 때마다 +4).

## 벽돌
| 종류 | 모양 | 효과 |
|---|---|---|
| 데이터 벽 | 회색, 숫자=내구도(1~2) | 효과 없음. 길만 막음 |
| ⚔ 공격 | 흰 바탕+칼 | 깨면 이번 전투 공격력 +1 (+수확) |
| 🛡 방어 | 흰 바탕+방패 | 방어도 +2 (+수확) |
| ♥ 체력 | 흰 바탕+하트 | 체력 +4 |
| 독 | 붉은 테두리+해골 | 깨면 릭 독 +1 |
| 돌 | 검정(보스 소환) | 내구도 3~4 |
특수 벽돌은 한 줄에 최대 1개(독은 별도 1개).

## 구슬 (큐 = 코드의 덱, 한 턴에 하나씩, 다음 구슬 미리 표시)
구슬은 24종(등급·해금은 아래 "등급·컬렉션", 전체 목록은 `docs/tasks/03-collection.md`). 아래 표는 처음부터 있던 7종이다.
시작 큐: 기본 2, 폭탄 1. **큐는 최대 5개**(`DECK_MAX`). 가득 차면 보상·브로커의 새 구슬은 "구슬을 바꾼다" 화면에서 가진 구슬 하나와 바꾼다(취소하면 아무것도 잃지 않고, 브로커에게는 바꾼 뒤에야 값을 치른다).
구슬 위력(`ORB_BONUS`): 묵직한 +2(+는 +3), 나머지 0. 관리자 구슬의 화면 설명은 "추가 피해 = 가진 크레딧 ÷ 25".
구슬마다 고유 도트 스프라이트가 있고(묵직한 구슬은 더 크게), 날아가는 동안 짧은 잔상을 남긴다(독 구슬은 붉은 잔상). 벽돌에 부딪힌 순간 짧은 충격 표시가 뜬다.
| 구슬 | 효과 |
|---|---|
| 기본 | 없음 |
| 폭탄 | 처음 부순 벽돌 주변 8칸 1피해 |
| 송곳 | 아무 벽돌이나 3개까지 관통·파괴 |
| 방패 | 벽돌 파괴마다 방어도 +1 |
| 분열 | 3갈래 발사. 갈래 하나의 피해 = 전체 피해 ÷ 3(올림, 최소 1) |
| 독 | 천장 타격마다 버그 독 +1 |
| 묵직한 | 구슬 위력 +2 (+는 +3) |

### 등급·컬렉션
구슬 24종·칩 40종에 등급(일반·고급·희귀·전설, 가중치 60·28·10·2)이 있다(`RARITY`). 보스 보상은 칩 후보 중 희귀 1장 보장(전설 확률은 어디서나 같다). 심층부는 층마다 희귀·전설 ×1.1. 브로커 값도 등급으로 정한다. 일부 구슬은 트로피·심층부 기록으로 해금된다(`ORBS[*].lock`). 손에 넣은 구슬·칩은 터미널의 **아카이브**에 남는다(`META.seen`). 전체 목록은 `docs/tasks/03-collection.md`.

### 구슬 강화(+)
**확률 다회 강화(+1~+5).** +1은 아래 표의 고유 효과, +2부터는 단계마다 구슬 위력 +1. 성공률은 지금 단계 기준 90/70/50/35/20%(`UP_RATE`). +3 이상에서 실패하면 한 단계 내려가고, 그 아래에서는 실패해도 그대로다. 큐(`RUN.deck`)에는 `bomb+`(+1), `bomb+2`…로 저장한다(예전 `bomb+` 저장과 호환).
구슬 보상의 "구슬 강화" 카드 또는 브로커의 "구슬 강화"(크레딧 30)로 큐의 구슬 1개를 강화한다. 숫자를 키우는 대신 구슬 고유 효과를 한 단계 올린다. 큐에는 `bomb+`처럼 저장되고, 이름 끝에 +가 붙으며 발사대 옆에 + 도트가 뜬다.
| 구슬+ | 효과 |
|---|---|
| 기본+ | 천장을 한 번 더 칠 수 있다 |
| 폭탄+ | 주변 8칸에 2씩 피해 |
| 송곳+ | 5개까지 관통 |
| 방패+ | 파괴마다 방어도 +2 |
| 분열+ | 5갈래, 피해 ÷ 5 |
| 독+ | 천장 타격마다 독 +2 |
| 묵직한+ | 구슬 위력 +3 |

## 칩 (접속 내내 유지)
40종, 등급 4단계(일반·고급·희귀·전설 각 10종). 효과는 덧셈·규칙 변경만 두고 곱연산은 없다(AGENTS.md). 전체 목록과 효과는 `docs/tasks/03-collection.md`, 수치는 `js/data.js`의 `RELICS`. 대표: 콤보 카운터(타격 상한 +1), 카운터 스크립트(막은 방어도의 절반 반사), 무정전 전원(연속 공격 첫 타 무시), 확장 슬롯(큐 +1칸), 백업 전원(전투당 1회 체력 1로 버팀), 벽 해체기(버그 턴마다 맨 아래 벽돌 1개 파괴).

## 모듈 (영구 성장, 코드의 스킬 트리 `TREE`)
- 커밋(코드의 포인트 `pts`): **칸을 처음 돌파할 때** +1, **세션 보스를 처음 돌파할 때** +3(`PTS`). 본편 25칸 전부 = 35점. 심층부도 `abyssBest` 기준으로 같은 규칙.
- 트리 전체 비용 108점: 본편만으로는 1/3 정도. 나머지는 심층부를 내려가며 채운다(다 설치하기 어렵게).
- 터미널·"연결이 끊겼다" 화면에서 진입. 모듈을 눌러 설명 → "설치하기". 앞 모듈을 설치해야 다음이 열린다("앞 모듈을 먼저 설치해야 열린다"). 효과는 새 접속부터.
- 십자 4갈래(공격·방어·구슬·재물), 갈래마다 줄기 2개(2·3점) → 두 가지로 갈라져 일반 모듈(3점) → **코어 모듈(8점, 마름모, 코드의 핵심 노드 `key`)**. 곱연산은 코어 모듈에만. 화면에서는 "곱연산"이라는 말 대신 "피해를 몇 배로 키운다"로 쓴다.

| 갈래 | 줄기 | 가지 A → 코어 모듈 | 가지 B → 코어 모듈 |
|---|---|---|---|
| 공격(위) | 최적화(기본 공격력 +1) → 멀티스레드(천장 상한 +1) | 부스트(⚔ 벽돌 +1) → **킬 스위치**(절반 이하 버그 피해 ×1.5) | 파이프라인(세 번째 타격부터 +1) → **포크 폭탄**(피해 ×1.5) |
| 방어(아래) | 메모리 증설(최대 체력 +4) → 방화벽 규칙(시작 방어도 +2) | 자동 복구(승리 시 체력 +2) → **예외 처리**(받는 피해 ×0.75) | 이중화(🛡 벽돌 +1) → **제로 트러스트**(얻는 방어도 ×1.5) |
| 구슬(왼쪽) | 컴파일 숙련(시작 폭탄 → 폭탄+) → 프로파일러(구슬 후보 +1) | 재시도 로직(다시 스캔하기 +1) → **동기화**(강화 구슬 피해 ×2) | 정밀 연산(조준선 -15%) → **대역폭**(묵직한·폭탄 피해 ×2) |
| 자원(오른쪽, 코드 id `e*`) | 초기 자본(크레딧 +30) → 협상 봇(브로커 -20%) | 데이터 수집(전투 크레딧 +5) → **버그 바운티**(칩 하나로 출발) | 패치 노트(충전소·복구 패치 +5) → **재부팅**(접속마다 한 번 30%로 부활) |

## 트로피 (코드의 배지 `BADGES`, `META.badges` = { id: 받은 횟수 })
처음 받으면 화면 위에 알림("트로피 받음 · 이름") + 효과음, 다시 받으면 횟수만 오른다. 터미널 → 아카이브 화면의 트로피 구역: 받은 트로피는 실선 메달·횟수, 못 받은 트로피는 점선·?·조건을 보여 준다.

| 트로피 | 조건 |
|---|---|
| 원샷 | 체력이 가득 찬 버그를 천장 타격 한 번으로 쓰러뜨린다 |
| 트리플 킬 | 구슬 하나가 천장을 딱 세 번 쳐서 가득 찬 체력을 모두 깎는다(예: 피해 3, 체력 9) |
| OMNIS 정지 | 세션 5 최종 보스 격파 |
| 무결점 빌드 | 체력을 잃지 않고 보스 격파 |
| 스피드런 | 보스를 3턴 안에 격파 |
| 벽 해체 | 한 번 발사로 벽돌 12개 |
| 감염 / 역공 | 독 / 반격으로 마지막 체력을 깎는다 |
| 경량화 | 큐에 구슬 3개 이하로 최종 보스 격파 |
| 심층부 바닥 | 심층부 5층 보스 격파 |
| 고래 | 한 접속에서 크레딧 200 |
| 첫 번째 새벽 | 보안 등급 6에서 근원 "규칙 0"을 멈춰 진 엔딩 |
| 독의 길 / 폭파의 길 / 저주의 길 / 실드의 길 / 갈래의 길 | OMNIS를 멈춘 순간 큐 구슬의 절반 이상이 그 계열(`BUILD_BADGES`) |

## 이야기 "마지막 번개"와 최종 목표 (2026-10-30, 대본 `docs/SCENARIO.md`)
- **왜 내려가는가**: OMNIS가 하늘을 쇠창살 패널로 닫은 세계. 15살 릭은 몸이 굳어 가는 동생 **리나**의 치료 기록을 찾아, 데이터 골짜기 맨 아래 제로 코어까지 내려간다. 무선이 없는 쇠구슬과 MP3 플레이어만 OMNIS가 못 건드린다.
- 데이터: 층·인물·장면·반복 대사는 `js/story.js`(`FLOORS`·`SPEAKER`·`SCRIPT`·`BARKS`), 보여 주기는 `js/talk.js`.
  - **대사 장면**(FULL): 화면 아래쪽에 한 줄씩. 화면 어디를 눌러도 다음 줄, **건너뛰기 버튼이 늘 보인다**(이어진 장면 전체를 건너뛴다). 처음 한 번만 보고 `META.story`에 남는다. 다시 오면 짧은 무전(`again`)만.
  - **무전 띠**(RADIO): 구슬 줄 위에 겹쳐 뜨는 한두 줄. 전투를 막지 않고 2.6초마다 넘어가며 누르면 바로 다음. 판의 천장·버그 예고를 가리지 않으려고 구슬 줄 자리를 쓴다.
  - 연출용 무작위(반복 대사 고르기)는 `Math.random`. 게임 결과에 영향이 없다.
- **층 = 깊이**(지도는 위에서 아래로 내려간다): 1층 침묵의 지상 폐허(지상) → 2층 암호화된 서버 숲(2km) → 3층 다중 감각의 감옥(5km) → 4층 사장된 도서관(8km) → 5층 제로 코어(10km). 지도 머리의 깊이 띠가 지나온 층을 채우고, 지도 바탕은 층마다 한 단계씩 어두워진다. 지도 아래 한 줄은 `FLOORS[s].line`.
- **층 보스**(규칙은 같은 `MON.boss` 패턴, 이름·그림·분노 배너만 층마다 다름): 센티넬 하이브-01 → 코테크 → 제미디 → 클라드. 5층은 OMNIS(`MON.lord`). 분노 배너 첫 줄은 그 보스가 실제로 하는 일(조준 가속·벽돌 낙하·독)과 맞는 말만 쓴다.
- **보스 장면**: 보스 칸에 처음 들어서면 등장 장면(FULL) → 전투 시작 때 보스 방 무전("위로 돌려 보내" = 천장 타격이 보스 피해) → 분노 때 동료 무전 → 처음 쓰러뜨리면 퇴장 장면(FULL) → 보상.
- **구슬 해금(시나리오 D3)**: 보스를 처음 쓰러뜨리면 그 보스가 남긴 구슬이 보상·브로커 후보에 풀린다. 1층 폭탄, 2층 송곳, 3층 분열, 4층 혜성(`ORBS[*].lock = { best:5n }`). 풀리면 알림 "구슬 해금 · …".
- **반복 플레이의 이유(리뷰 S3)**: OMNIS는 릭이 돌아가면 백업으로 해방된 AI를 다시 덮는다. 코테크를 풀어 준 뒤의 출발 무전과 보스 재등장 무전이 이 사실을 말한다.
- **첫 정지 = 결말 1 "99%"**(`SCRIPT.end1`): 치료 열쇠가 99%에서 멈춘다. 마지막 1%는 OMNIS 뿌리의 "규칙 0"에 잠겨 있고, OMNIS는 재부팅하며 보안 등급을 올린다 → **보안 등급 1**이 열린다. 하늘·치료·풀(대본의 큰 보상)은 진 엔딩까지 아낀다(리뷰 S4).
- **보안 등급 단계**(`ASC`, 누적): 열린 최고 단계를 깨면 다음 단계가 열리고 터미널에서 바로 골라진다. 터미널의 보안 등급 버튼을 누를 때마다 0 → 열린 단계까지 돈다. 심층부에는 걸리지 않는다.
  | 단계(이름은 `ASC[n].name`) | 규칙 |
  |---|---|
  | 1 | 정예가 처음부터 분노(조준 가속) |
  | 2 | 정예도 3턴마다 벽돌 1개 낙하 |
  | 3 | 보스 처치 후 체력 회복 없음(최대 체력 +4만) |
  | 4 | 모든 전투의 데이터 벽에 독 벽돌(줄마다 25%) |
  | 5 | 보스전에서 천장 1칸 봉인 |
  | 6 | OMNIS를 멈춘 뒤 같은 체력으로 근원 "규칙 0" |
- **박사의 기록**: 보안 등급 1~5를 처음 깰 때마다 한서진 박사의 음성 기록 하나(`SCRIPT.a1`~`a5`). 규칙 0("아무도 다치지 않게")이 어떻게 하늘을 닫았는지.
- **근원 "규칙 0"**(`MON.king`, 기본 체력 30 → 5층 기준 약 43): 천장 2칸 **봉인**(빗금, 닿아도 타격 없음·타격 횟수도 안 씀) = "닫으면 다치지 않는다". 2페이즈(체력 절반)부터 봉인이 매 턴 한 칸씩 옆으로 옮기고 다음 자리를 붉은 점선으로 예고, 3페이즈에 봉인 3칸. 전투 난수는 OMNIS와 갈라 같은 판이 되지 않게. OMNIS를 잡으면 승리 회복 없이 그 체력 그대로 `RUN.king`을 저장해 새로고침해도 근원부터(`fixRun`은 보안 등급 6·5층·보스 칸 대기일 때만 유지).
- **진 엔딩 "첫 번째 새벽"**(`SCRIPT.end`·`end2`·`end3`): 창살이 열리고, 리나가 컵을 쥐고, 폐허 틈의 풀을 만진다. 다시 깨면 풀 장면(`end3`)만. 무너진 코어 아래 지워지지 않은 백업들 = 심층부.
- 본 장면은 아카이브의 **이야기** 구역에서 다시 읽는다(`STORY_ORDER`).
- 옛 이야기(디버거·하람·화요일의 알고리즘)의 `META.story` 키(`intro` 등)는 그대로 두지만 쓰지 않는다. 새 장면은 새 키라 이미 본 플레이어도 새 프롤로그를 본다.
- 그림: 릭·층 보스·초상은 지금 **더미**(`tools/make_dummy_assets.py`, 목록 `docs/assets/DUMMY.md`). 같은 파일 이름으로 바꿔 넣으면 된다.

## 접속 = 5세션, 그 뒤 심층부
- 본편은 **세션 5개**(`FINAL_S = 4`). 세션 5 보스는 최종 보스 "OMNIS"(지도에 "최종"). 이기면 "OMNIS를 멈췄다" 화면 → 터미널. 저장은 지우고 `META.clears`를 올린다.
- **심층부**: 본편을 한 번 깨면 터미널의 "심층부로"가 열린다(잠겼을 때 "심층부 · OMNIS를 멈추면 열린다"). 새 큐로 들어가는 별도 접속(`RUN.abyss`)이고 끝이 없다.
  - 버그: 심층부 n층 = 본편 n세션 세기 × 체력 1.25^n, 공격 +n(`ABYSS`). 첫 칸부터 아무 버그나 나온다. 이름 앞에 "심층부의".
  - 화면: `html[data-realm="abyss"]`로 테마와 무관하게 검붉은 토큰, 패널은 석판, 캔버스에 붉은 불씨·천장 균열, 머리띠·지도 제목이 붉다. 음악은 `abyss`(지도)·`deep`(전투).
  - 순위표: 본편 25칸 위에 이어 센다(심층부 1층 1칸 = 26).

## 접속 구조
- 지도 화면: 던전 그림을 옅게 깐 협곡. **첫 구역이 맨 위, 보스가 맨 아래**(내려간다). 구역은 메달(전투 = 칼 도트, 정예 = 붉은 해골 도트, 충전소(코드 `rest`) = 충전소 그림, 브로커(코드 `shop`) = 브로커 그림, 보스 = 그 층 보스 그림)이고 이름이 아래에 붙는다. **어떤 버그인지는 들어가기 전까지 모른다.** 정예·보스는 붉은 테. 구역들은 위 줄부터 차례로 내려앉는다. 낮은 화면에서는 메달을 지도 높이에 맞춰 44px까지 줄인다. 갈 수 있는 구역은 테두리가 진하고 통통 튄다.
- 브로커·충전소 화면 위쪽에 장면 캔버스(`js/scene.js`): 떠돌이 브로커는 카운터 뒤 브로커(랜턴 깜빡임)와 진열된 구슬·크레딧, 충전소는 어두운 던전의 충전소(3프레임)·불티·쉬는 릭. 동작 줄이기 설정이면 멈춘 그림.
- 세션 = 갈림길 지도 5갈래 × 4칸 + 보스(이전 3갈래 저장 지도도 그대로 그린다). 같은 칸으로는 항상, 옆 칸으로는 40% 확률로 연결.
- 지도 구역: 전투(크레딧 10~14만, 보상 화면 없이 지도로), 정예(칩 3택1 → 구슬 보상 + 크레딧 22~28), 충전소(체력 40% 회복만, 아니면 "지나가기"), 브로커(구슬 2개·칩 1개는 등급별 값: 구슬 18/26/38/55, 칩 35/50/70/95. 패치 15, 강화 30, 구슬 빼기 25. 협상 봇 -20%, 난수 시드 -10%, 채굴 중독 +15. 산 물건은 "품절", 나갈 때 "떠나기"), 보스(칩 3택1 → 구슬 보상 + 최대 체력 +4 + 체력 절반 회복 + 크레딧 40 → 다음 층).
- 구슬 보상(구슬 3택1 또는 구슬 강화·건너뛰기·다시 스캔하기)은 **정예·보스 처치 때만** 나온다. 매 전투마다 큐가 불면 구슬 하나의 무게가 가벼워져서다. 그 밖의 구슬은 브로커에게서 산다.
- 첫 칸은 메모리 누수 고정(본편). 세션 5 보스 OMNIS를 멈추면 본편이 끝난다.

## 버그 (기본값, 실제 체력 = 기본 × WALL.hpMul(0.6) × (1 + 0.35×세션), 최소 3)
패턴의 "공격 n턴" = n턴 연속으로 매 턴 공격력만큼 때린다(배율 없음). 패턴은 끝까지 가면 처음부터 반복.
| 버그 | 체력 | 공 | 방 | 조준선 속도 | 패턴 |
|---|---|---|---|---|---|
| 메모리 누수 | 6 | 1 | 0 | 0.9 | 공격 2턴, 대기 |
| 스팸봇 | 8 | 1 | 0 | 1.0 | 공격 3턴, 대기 |
| 방화벽 | 9 | 1 | 2 | 1.15 | 공격 2턴, 방어 +2 |
| 바이러스 | 9 | 1 | 1 | 1.3 | 공격 2턴, 독 +⚔(공격력만큼), 공격 2턴, 포자(독 벽돌 소환) |
| 층 보스(1~4층: 센티넬 하이브-01·코테크·제미디·클라드) | 14 | 1 | 1 | 1.4 | 공격 3턴, 돌 소환 / 체력 절반에서 2페이즈(공+1, 방+2): 공격 4턴, 돌 소환 |
| OMNIS(세션 5 최종) | 24 | 1 | 1 | 1.4 | 공격 2턴·돌 소환·방어 +3 / 2/3에서 2페이즈: 공격 3턴·소환 / 1/3에서 3페이즈: 공격 3턴·독 +2·소환 (페이즈마다 공+1, 방+2) |
- 보스 연속 공격 턴 수를 짧게 둔 이유: 공격력이 세션마다 +1이라 6턴이면 3세션 2페이즈 한 묶음이 4×6=24(최대 체력 전부)가 됐다.
- 세션당: 공·방 +1, 조준선 +0.1(최대 2.0). 정예: 체력 ×1.5, 방어 +1, 조준선 +0.1. (2026-10: 기본 조준 속도를 약 25% 낮추고, 정예·보스의 가속으로 긴장을 옮겼다)
- 데이터 벽: 밀도 기본×0.5, 시작 3줄, 2턴마다 하강(소환·포자 행동 시 즉시).
- 지도 노드 가중치(2~4칸): 전투 45, 정예 10(2칸)/16, 상점 17, 휴식 18/34(4칸). 이어진 앞 칸이 휴식이면 휴식이, 상점이면 상점이 나오지 않는다(연속 금지).
- 보스 벽돌 낙하: 패턴과 별개로 3턴마다(분노 페이즈부터 2턴마다) 오버플로선 위 두 줄을 뺀 아무 칸에 벽돌 1 + ⌊깊이/2⌋개(본편 1·1·2·2·3, 심층부는 층+2 기준). 이미 벽돌이 있으면 그 벽돌 체력 +1. 낙하 턴에는 행동 예고 옆에 붉은 벽돌과 개수가 뜬다. 칸별 일반 버그: 1칸 메모리 누수, 2칸 스팸봇·방화벽, 3칸 방화벽·바이러스, 4칸 전부.

- 접속 저장의 `abyss`(심층부 접속)·`revived`(재부팅 사용)·`pts`(이번 접속에서 받은 포인트)·`badges`는 v2 시절 추가 필드로 늘었다. 옛 출발 선물(`gift`·`giftStock`) 필드는 기능이 빠져 이어할 때 비운다.
- `brickquest:theme:v1`: 화면 테마(`auto`·`light`·`dark`).
- `brickquest:profile:v2`: 플레이어 id(비공개 UUID), 닉네임, 마지막 닉네임 변경 시각(`nameAt`), 서버 등록 여부, 아직 못 올린 접속 기록 대기열(최대 50개, 넘치면 최고 기록은 남기고 오래된 것부터 버린다).
- 접속 상태에 `rid`(접속 UUID)가 있다. 기록 서버가 같은 접속을 두 번 세지 않게 하는 용도다(없던 이전 저장은 기록할 때 새로 만든다).
- 저장 시점: 노드 진입, 전투 승리, 보상 선택, 상점 구매, 강화 결과. 전투 도중 상태는 저장하지 않는다. 이어하면 그 전투를 처음부터 하되, 전투 난수가 칸마다 정해져 있어 같은 벽돌·덱 순서·첫 조준으로 시작한다(R06).

## 사운드 (`js/audio.js`, Web Audio 합성 + 음원 곡)
- BGM: `calm`(터미널·지도·충전소·브로커·보상. 2026-10-28부터 음원 `assets/audio/tuesdays-algorithm.mp3`(`TRACKS.calm`, 122bpm)을 틀고, 못 읽으면 합성곡 84bpm 가단조로 대신한다), `battle`(일반·정예 전투, 132bpm), `boss`(보스전, 150bpm 라단조, 톱니파 베이스), `abyss`(심연 지도, 66bpm 반음 진행), `deep`(심연 전투, 112bpm 단2도 리프). 패배하면 음악을 멈추고 패배 음을 낸다.
- 구슬별 소리: 벽돌 충돌은 파형·높이가 구슬마다 다르다(송곳=톱니 "지직", 독=물방울, 묵직한=낮은 쿵, 방패=맑은 금속). 같은 구슬의 연속 충돌은 반음씩 올라간다(최대 한 옥타브). 천장 타격은 가장 밝고 큰 상승 화음이고, 같은 구슬의 2·3번째 타격은 더 높다.
- 그 밖: 발사, 돌(둔탁), 폭탄 폭발, 버그 피격(3 이상이면 묵직하게)·쓰러짐, 릭 피격·방어, 강화 벽돌 도착(공·방·체·독), 데이터 벽 하강·붕괴, 보스 등장·분노, 승리·패배, 브로커 입장·구매, 충전소 입장·회복, 카드 고르기.
- 같은 소리가 몰리면(분열·폭탄) 이름별 최소 간격(약 30ms)으로 거른다. 마지막에 압축기를 둬 겹쳐도 찢어지지 않게 한다.
- 설정 `brickquest:audio:v1`: `{ bgm, sfx }`. 기본은 둘 다 켬. 탭이 숨으면 소리를 멈춘다.

## 호출명·순위표 (코드의 닉네임·랭킹·기록 서버)
- 호출명(코드의 닉네임) = 맛·감각 꾸밈말 + 성격 꾸밈말 + 디지털 사물, 모두 3음절(약 15만 가지. 사물은 릭의 세계에 있을 법한 것만, 목록은 `NICK_C`). 터미널에 처음 들어올 때 임의로 정해지고, 이후 터미널의 "변경"으로 **일주일에 한 번** 직접 입력한 닉네임으로 바꿀 수 있다(한글·영문·숫자·공백 2~12자, 앞뒤·연속 공백 없음, 중복 불가, **금지어 불가**: 욕설·성적·혐오 표현·운영자 사칭. 소문자로 바꾸고 공백·숫자를 지운 뒤, 영문을 뺀 꼴·한글을 뺀 꼴까지 부분 문자열로 찾아 "시1발"·"f u c k"·"시a발" 같은 우회도 거른다. 목록 `BAD_NAME`은 서버와 `js/profile.js`가 같고 회귀 검사가 둘이 같은지, 자동 닉네임이 하나도 걸리지 않는지 확인한다). 형식·중복·7일 제한은 서버(`POST /api/rename`, `players.name_at`)가 최종 판정하고, 동시에 두 번 보내도 한 번만 바뀐다. 오프라인이면 바꿀 수 없다("인터넷에 연결해야 바꿀 수 있다"). 서버에서 이름이 겹치면 시스템이 다시 뽑는다.
- 접속이 끝날 때(쓰러짐·포기·저장된 접속 덮어쓰기·완주) 그 접속의 도달 칸 수(`세션×5 + 마지막으로 완료한 칸`, 심층부는 +25)를 올린다. 서버는 플레이어별 최고 기록을 유지한다. 접속 시작과 지도 화면마다 접속 시작 표(`/api/start`)를 보낸다. 서버는 시작 표를 받은 뒤 칸당 5초 이상 지난 기록만 그대로 순위표에 쓰고, 그 밖(오프라인에서 시작·옛 버전·너무 빠름)은 5칸까지만 반영한다(위조 비용 올리기. 모든 API에 속도 제한).
- 개인정보(2026-10-26): 터미널 맨 아래 `개인정보 처리방침`(privacy.html)·`내 기록 삭제`(버튼 "순위표 기록 지우기"를 두 번 눌러 확정 → `/api/delete`로 서버의 호출명·접속 기록·시작 표 삭제, 기기에는 새 id·새 호출명. 진행도는 남는다).
- 순위표: 최고 기록 내림차순, 같으면 먼저 세운 쪽이 위. 터미널에 상위 3명 + 내 줄, 순위표 화면에 상위 10명 + 내 줄. 불러오지 못하면 "순위표를 불러오지 못했다". 내 줄은 반전 색. 1위도 붉게 칠하지 않는다(붉은색 = 위험).

## 설계 원칙 (지금까지의 결정과 이유)
- 실시간 패들 대신 턴제 조준 발사: 위아래 두 화면을 번갈아 볼 수 있어야 전략이 생긴다.
- 천장 타격: "벽돌을 깨면 무조건 공격"이면 조준할 이유가 없어서. 데이터 벽을 뚫는 공간적 목표를 준다.
- 부숴도 튕김: 한 발 한 발의 각도가 중요해지도록. 대신 데이터 벽 하강을 2턴 주기로 늦췄다.
- 질적 성장: 공격력 누적은 숫자 인플레이션과 운 의존을 만들었다. 숫자는 작게, 성장은 구슬·칩로.
- 움직이는 조준선: 피지컬(타이밍) 요소. 등속 왕복이라 어느 각도든 난이도가 같다.
