# 브릭 크롤 게임 디자인 문서 (현재 구현 기준)

## 한 줄 요약
움직이는 조준선에 타이밍을 맞춰 구슬을 쏘고, 내려오는 성벽을 깎아 **천장에 닿게 해야** 위쪽의 몬스터를 때리는 턴제 벽돌깨기 로그라이크.

## 화면
- 위 110px: 전투(왼쪽 기사, 오른쪽 몬스터, 체력·공격·방어, 몬스터의 다음 행동 예고).
  - 몬스터 공격 예고: 머리 위 붉은 ⚔ + 숫자 = **남은 연속 공격 턴 수**. 매 턴 아래 ⚔ 숫자(공격력)만큼 때리고, 붉은 숫자는 3 → 2 → 1로 줄어든다. 예: ⚔2에 붉은 3이면 3턴 동안 2씩, 총 6.
  - 이유: 예전엔 배율(×2.5) 강공격이 있어 아래 ⚔ 숫자와 실제 피해가 어긋났다. 이제 한 번의 피해는 언제나 아래 ⚔ 숫자 그대로다.
- 아래: 벽돌판. 맨 위 굵은 선 = 천장, 중간 점선 = 붕괴선, 맨 아래 = 발사대.
- DOM: 헤더(세션·칸·이름, 코인·턴), 구슬 줄(이번 구슬 초상화 + "발사 대기"/"발사!", 다음 구슬), 유물 칩, 오버레이(메인·랭킹·지도·선택·메뉴).
- 메인 화면: 도트 로고, 구슬 진열, 플레이어 닉네임, 기록 줄, **시작 버튼 하나만 화려하게**(이어할 원정이 있으면 이어하기, 없으면 새 원정: 석판 그림·크게·빛 띠·▶ 깜빡임), 심연 버튼(붉은 테 석판, 잠기면 점선), 보조 버튼(스킬 트리·배지, 얇은 테), 랭킹 상위 3명, 음악·효과음·테마.
- 오버레이는 위에서부터 쌓고 첫·끝 요소의 auto 여백으로 가운데 정렬한다. `justify-content:center` + 스크롤이면 넘친 위쪽(로고)이 스크롤로도 안 보이는 문제가 있었다.

## 한 턴의 흐름
1. 조준선이 일정 속도로 좌우 왕복(삼각파). 턴마다 시작 위치·방향 무작위. 시작 0.2초는 입력 무시.
   - 가속: 정예는 체력 절반 이하에서 ×1.35(배너 "정예가 날뛴다"), 보스는 페이즈마다 +30%(2페이즈 ×1.3, 최종 보스 3페이즈 ×1.6). 가속 중에는 발사대 양옆에 붉은 화살표가 깜빡인다.
2. 탭/Space로 발사. 이번 구슬 하나를 쏜다(분열 구슬은 3갈래).
3. 구슬이 벽돌을 부숴도 **튕긴다**(송곳 구슬만 관통). 천장에 닿으면 몬스터 타격(구슬당 최대 3회). **피해 = 기사 공격력(⚔) + 구슬 보정** (+ 연쇄) → 핵심 노드 배율. 구슬 줄에 `⚔2 + 1 = 3`처럼 식으로 뜬다(⚔ 벽돌을 깨면 왼쪽, 센 구슬이면 가운데 숫자가 오른다).
4. 구슬이 바닥에 닿으면 끝. 처음 돌아온 구슬 위치가 다음 발사 위치.
5. 몬스터 독 틱 → 몬스터 행동 → (2턴마다) 성벽 한 줄 하강 + 새 줄 → 붕괴선 넘은 벽돌은 기사에게 1개당 2 피해 → 기사 독 틱.

## 피해 규칙
- 방어도 = 체력 앞의 보호막. 피해를 먼저 흡수하고 흡수한 만큼 깎인다. 기사·몬스터 동일.
- 독 = 스택. 턴마다 스택만큼 피해(방어도 무시) 후 1 감소. 체력바 끝이 다음 틱 피해만큼 붉게 표시.
- 공격력·방어도는 전투마다 초기화(공격 1(+날 세우기), 방어 0, 갑옷·방패술만 시작 방어도). 체력은 원정 내내 이어진다(최대 24에서 시작, 보스를 잡을 때마다 +4).

## 벽돌
| 종류 | 모양 | 효과 |
|---|---|---|
| 성벽 | 회색, 숫자=내구도(1~2) | 효과 없음. 길만 막음 |
| ⚔ 공격 | 흰 바탕+칼 | 깨면 이번 전투 공격력 +1 (+수확) |
| 🛡 방어 | 흰 바탕+방패 | 방어도 +2 (+수확) |
| ♥ 체력 | 흰 바탕+하트 | 체력 +4 |
| 독 | 붉은 테두리+해골 | 깨면 기사 독 +1 |
| 돌 | 검정(보스 소환) | 내구도 3~4 |
특수 벽돌은 한 줄에 최대 1개(독은 별도 1개).

## 구슬 (덱, 한 턴에 하나씩, 다음 구슬 미리 표시)
시작 덱: 기본 2, 폭탄 1. **덱은 최대 5개**(`DECK_MAX`). 가득 차면 보상·상점의 새 구슬은 "구슬을 바꾼다" 화면에서 가진 구슬 하나와 바꾼다(취소하면 아무것도 잃지 않고, 상점은 바꾼 뒤에야 값을 치른다).
구슬 보정(`ORB_BONUS`): 묵직한 +2(+는 +3), 나머지 0.
구슬마다 고유 도트 스프라이트가 있고(묵직한 구슬은 더 크게), 날아가는 동안 짧은 잔상을 남긴다(독 구슬은 붉은 잔상). 벽돌에 부딪힌 순간 짧은 충격 표시가 뜬다.
| 구슬 | 효과 |
|---|---|
| 기본 | 없음 |
| 폭탄 | 처음 부순 벽돌 주변 8칸 1피해 |
| 송곳 | 아무 벽돌이나 3개까지 관통·파괴 |
| 방패 | 벽돌 파괴마다 방어도 +1 |
| 분열 | 3갈래 발사 |
| 독 | 천장 타격마다 몬스터 독 +1 |
| 묵직한 | 구슬 보정 +2 (+는 +3) |

### 구슬 강화(+)
휴식의 "단련" 또는 상점 "구슬 강화"(30코인)로 덱의 구슬 1개를 강화한다. 숫자를 키우는 대신 구슬 고유 효과를 한 단계 올린다. 덱에는 `bomb+`처럼 저장되고, 이름 끝에 +가 붙으며 발사대 옆에 + 도트가 뜬다.
| 구슬+ | 효과 |
|---|---|
| 기본+ | 천장을 한 번 더 칠 수 있다 |
| 폭탄+ | 주변 8칸에 2씩 피해 |
| 송곳+ | 5개까지 관통 |
| 방패+ | 파괴마다 방어도 +2 |
| 분열+ | 5갈래 |
| 독+ | 천장 타격마다 독 +2 |
| 묵직한+ | 구슬 보정 +3 |

## 유물 (원정 내내 유지)
천장 연타(타격 상한+1, 최대 2), 반격(방어로 막은 만큼 반사), 해독(독 감소 2), 집중(조준선 15% 감속, 최대 2), 지지대(붕괴 피해 1), 수확(강화 벽돌 +1, 최대 2), 구급상자(승리 시 체력 +2, 최대 2), 갑옷(전투 시작 방어도 +3, 최대 2), 흡혈(구슬 하나가 천장을 세 번째 칠 때 체력 +1), 인내(몬스터 연속 공격의 첫 타를 막는다).

## 스킬 트리 (영구 성장)
- 포인트: **칸을 처음 돌파할 때** +1, **세션 보스를 처음 돌파할 때** +3(`PTS`). 본편 25칸 전부 = 35점. 심연도 `abyssBest` 기준으로 같은 규칙.
- 트리 전체 비용 108점: 본편만으로는 1/3 정도. 나머지는 심연을 내려가며 채운다(다 찍기 어렵게).
- 메인·실패 화면에서 진입. 노드를 눌러 설명 → "찍기". 앞 노드를 찍어야 다음이 열린다. 효과는 새 원정부터.
- 십자 4갈래, 갈래마다 줄기 2개(2·3점) → 두 가지로 갈라져 일반 노드(3점) → **핵심 노드(8점, 마름모)**. 곱연산은 핵심 노드에만.

| 갈래 | 줄기 | 가지 A → 핵심 | 가지 B → 핵심 |
|---|---|---|---|
| 공격(위) | 날 세우기(기본 공격력 +1) → 연타(천장 상한 +1) | 전투 함성(⚔ 벽돌 +1) → **처형자**(절반 이하 몬스터 피해 ×1.5) | 연쇄(세 번째 타격부터 +1) → **파괴자**(피해 ×1.5) |
| 방어(아래) | 단련된 몸(최대 체력 +4) → 방패술(시작 방어도 +2) | 재생(승리 시 체력 +2) → **불굴**(받는 피해 ×0.75) | 단단한 벽(🛡 벽돌 +1) → **철벽**(얻는 방어도 ×1.5) |
| 구슬(왼쪽) | 숙련(시작 폭탄 → 폭탄+) → 눈썰미(구슬 후보 +1) | 재도전(다시 뽑기 +1) → **공명**(강화 구슬 피해 ×2) | 정조준(조준선 -15%) → **대구경**(묵직한·폭탄 피해 ×2) |
| 경제(오른쪽) | 두둑한 주머니(코인 +30) → 흥정(상점 -20%) | 전리품(전투 코인 +5) → **보물 사냥꾼**(유물 하나로 출발) | 약초학(휴식·약초 +5) → **불사조**(원정마다 한 번 30%로 부활) |

## 배지 (`BADGES`, `META.badges` = { id: 획득 횟수 })
처음 따면 화면 위에 알림 + 효과음, 다시 따면 횟수만 오른다. 메인 → 배지 화면: 딴 배지는 실선 메달·횟수, 못 딴 배지는 점선·?·조건을 보여 준다.

| 배지 | 조건 |
|---|---|
| 일격 | 체력이 가득 찬 몬스터를 천장 타격 한 번으로 쓰러뜨린다 |
| 삼연타 | 구슬 하나가 천장을 딱 세 번 쳐서 가득 찬 체력을 모두 깎는다(예: 피해 3, 체력 9) |
| 탑의 정복자 | 세션 5 최종 보스 격파 |
| 무결 | 체력을 잃지 않고 보스 격파 |
| 속전속결 | 보스를 3턴 안에 격파 |
| 철거반 | 한 번 발사로 벽돌 12개 |
| 독살 / 되갚기 | 독 / 반격으로 마지막 체력을 깎는다 |
| 가벼운 짐 | 구슬 3개 이하 덱으로 최종 보스 격파 |
| 심연의 바닥 | 심연 5층 보스 격파 |
| 큰손 | 한 원정에서 코인 200개 |

새 배지는 `BADGES`에 한 줄 + 조건 자리에서 `earnBadge(id)`.

## 원정 = 5세션, 그 뒤 심연
- 본편은 **세션 5개**(`FINAL_S = 4`). 세션 5 보스는 최종 보스 "탑의 군주"(지도에 "최종"). 이기면 원정 완료 화면 → 메인. 저장은 지우고 `META.clears`를 올린다.
- **심연**: 본편을 한 번 깨면 메인의 "심연으로"가 열린다. 새 덱으로 들어가는 별도 원정(`RUN.abyss`)이고 끝이 없다.
  - 몬스터: 심연 n층 = 본편 n세션 세기 × 체력 1.25^n, 공격 +n(`ABYSS`). 첫 칸부터 아무 몬스터나 나온다. 이름 앞에 "심연의".
  - 화면: `html[data-realm="abyss"]`로 테마와 무관하게 검붉은 토큰, 패널은 석판, 캔버스에 붉은 불씨·천장 균열, 머리띠·지도 제목이 붉다. 음악은 `abyss`(지도)·`deep`(전투).
  - 랭킹: 본편 25칸 위에 이어 센다(심연 1층 1칸 = 26).

## 원정 구조
- 지도 화면: 던전 그림을 옅게 깐 탑. 칸은 메달(전투 = 칼 도트, 정예 = 붉은 해골 도트, 휴식 = 모닥불, 상점 = 상인, 보스 = 탑의 주인)이고 이름이 아래에 붙는다. **어떤 몬스터인지는 들어가기 전까지 모른다.** 정예·보스는 붉은 테. 칸들은 아래 줄부터 차례로 떠오른다. 갈 수 있는 칸은 테두리가 진하고 통통 튄다.
- 상점·휴식 화면 위쪽에 장면 캔버스(`js/scene.js`): 상점은 카운터 뒤 상인(랜턴 깜빡임)과 진열된 구슬·코인, 휴식은 어두운 던전의 모닥불(3프레임)·불티·쉬는 기사. 동작 줄이기 설정이면 멈춘 그림.
- 세션 = 갈림길 지도 5갈래 × 4칸 + 보스(이전 3갈래 저장 지도도 그대로 그린다). 같은 칸으로는 항상, 옆 칸으로는 40% 확률로 연결.
- 노드: 전투(구슬 3택1 또는 구슬 강화·건너뛰기·다시 뽑기 1회 + 코인 10~14), 정예(유물 3택1 + 코인 22~28), 휴식(체력 40% 회복 · 구슬 버리기 · 단련(강화) 중 하나), 상점(구슬 20/32, 유물 45, 약초 15, 강화 30, 버리기 25), 보스(유물 + 최대 체력 +4 + 체력 절반 회복 + 코인 40 → 다음 세션).
- 첫 칸은 슬라임 고정(본편). 세션 5 보스를 이기면 원정 완료.

## 몬스터 (기본값, 실제 체력 = 기본 × WALL.hpMul(0.6) × (1 + 0.35×세션), 최소 3)
패턴의 "공격 n턴" = n턴 연속으로 매 턴 공격력만큼 때린다(배율 없음). 패턴은 끝까지 가면 처음부터 반복.
| 몬스터 | 체력 | 공 | 방 | 조준선 속도 | 패턴 |
|---|---|---|---|---|---|
| 슬라임 | 6 | 1 | 0 | 0.9 | 공격 2턴, 대기 |
| 박쥐 | 8 | 1 | 0 | 1.0 | 공격 3턴, 대기 |
| 골렘 | 9 | 1 | 2 | 1.15 | 공격 2턴, 방어 +2 |
| 독버섯 | 9 | 1 | 1 | 1.3 | 공격 1턴, 독 +2, 공격 1턴, 포자(독 벽돌 소환) |
| 탑의 주인(보스) | 20 | 1 | 1 | 1.4 | 공격 3턴, 돌 소환 / 체력 절반에서 2페이즈(공+1, 방+2): 공격 4턴, 돌 소환 |
| 탑의 군주(세션 5 최종) | 24 | 1 | 1 | 1.4 | 공격 2턴·돌 소환·방어 +3 / 2/3에서 2페이즈: 공격 3턴·소환 / 1/3에서 3페이즈: 공격 3턴·독 +2·소환 (페이즈마다 공+1, 방+2) |
- 보스 연속 공격 턴 수를 짧게 둔 이유: 공격력이 세션마다 +1이라 6턴이면 3세션 2페이즈 한 묶음이 4×6=24(최대 체력 전부)가 됐다.
- 세션당: 공·방 +1, 조준선 +0.1(최대 2.0). 정예: 체력 ×1.5, 방어 +1, 조준선 +0.1. (2026-10: 기본 조준 속도를 약 25% 낮추고, 정예·보스의 가속으로 긴장을 옮겼다)
- 성벽: 밀도 기본×0.5, 시작 3줄, 2턴마다 하강(소환·포자 행동 시 즉시).
- 지도 노드 가중치(2~4칸): 전투 45, 정예 10(2칸)/16, 상점 17, 휴식 18/34(4칸). 칸별 일반 몬스터: 1칸 슬라임, 2칸 박쥐·골렘, 3칸 골렘·독버섯, 4칸 전부.

## 저장
- `brickquest:run:v2`: 원정 전체(세션, 체력, 코인, 덱(강화 구슬은 `bomb+`), 유물, 지도, 위치, 진행 중 노드, 대기 중 보상, 상점 재고, 출발 선물 대기·후보(`gift`·`giftStock`)). 추가 필드만 있고 이전 저장도 그대로 읽히므로 버전은 올리지 않았다.
- `brickquest:meta:v3`: 본편 최고 칸(`best`), 심연 최고 칸(`abyssBest`), 원정 횟수, 완주 횟수(`clears`), 스킬 포인트(`pts`), 찍은 노드(`tree`), 배지(`badges`).
  v2에서 옮길 때: 트리 노드가 새로 짜여 같은 id가 다른 효과가 됐으므로 찍은 노드는 비우고, 최고 기록으로 받을 포인트(`ptsUpTo(best)`)를 다시 계산해 준다. 예전 영혼석은 버린다. 25칸을 넘는 예전 기록(옛 심연)은 본편 완주로 본다.
- 원정 저장에 `abyss`(심연 원정)·`revived`(불사조 사용)·`pts`(이번 원정에서 받은 포인트)·`badges`가 늘었다(추가 필드라 v2 유지).
- `brickquest:theme:v1`: 화면 테마(`auto`·`light`·`dark`).
- `brickquest:profile:v1`: 플레이어 id(비공개 UUID), 닉네임, 서버 등록 여부, 아직 못 올린 원정 기록 대기열.
- 원정 상태에 `rid`(원정 UUID)가 있다. 기록 서버가 같은 원정을 두 번 세지 않게 하는 용도다(없던 이전 저장은 기록할 때 새로 만든다).
- 저장 시점: 노드 진입, 전투 승리, 보상 선택, 상점 구매. 전투 도중 상태는 저장하지 않음(이어하면 그 전투를 처음부터).

## 사운드 (`js/audio.js`, Web Audio 합성)
- BGM: `calm`(메인·지도·휴식·상점·보상, 84bpm 가단조, 드럼 없음), `battle`(일반·정예 전투, 132bpm), `boss`(보스전, 150bpm 라단조, 톱니파 베이스), `abyss`(심연 지도, 66bpm 반음 진행), `deep`(심연 전투, 112bpm 단2도 리프). 패배하면 음악을 멈추고 패배 음을 낸다.
- 구슬별 소리: 벽돌 충돌은 파형·높이가 구슬마다 다르다(송곳=톱니 "지직", 독=물방울, 묵직한=낮은 쿵, 방패=맑은 금속). 같은 구슬의 연속 충돌은 반음씩 올라간다(최대 한 옥타브). 천장 타격은 가장 밝고 큰 상승 화음이고, 같은 구슬의 2·3번째 타격은 더 높다.
- 그 밖: 발사, 돌(둔탁), 폭탄 폭발, 몬스터 피격(3 이상이면 묵직하게)·쓰러짐, 기사 피격·방어, 강화 벽돌 도착(공·방·체·독), 성벽 하강·붕괴, 보스 등장·분노, 승리·패배, 상점 입장·구매, 휴식 입장·회복, 카드 고르기.
- 같은 소리가 몰리면(분열·폭탄) 이름별 최소 간격(약 30ms)으로 거른다. 마지막에 압축기를 둬 겹쳐도 찢어지지 않게 한다.
- 설정 `brickquest:audio:v1`: `{ bgm, sfx }`. 기본은 둘 다 켬. 탭이 숨으면 소리를 멈춘다.

## 닉네임·기록 서버
- 닉네임 = 맛·감각 꾸밈말 + 성격 꾸밈말 + 사물, 모두 3음절(47×48×70 ≈ 15만 가지). 메인 화면에 처음 들어올 때 정하고 바꿀 수 없다. 서버에서 이름이 겹치면 시스템이 다시 뽑는다.
- 원정이 끝날 때(쓰러짐·포기·저장된 원정 덮어쓰기·완주) 그 원정의 도달 칸 수(`세션×5 + 마지막으로 완료한 칸`, 심연은 +25)를 올린다. 서버는 플레이어별 최고 기록을 유지한다.
- 랭킹: 최고 기록 내림차순, 같으면 먼저 세운 쪽이 위. 메인에 상위 3명 + 내 줄, 랭킹 화면에 상위 10명 + 내 줄. 내 줄은 반전 색. 1위도 붉게 칠하지 않는다(붉은색 = 위험).

## 설계 원칙 (지금까지의 결정과 이유)
- 실시간 패들 대신 턴제 조준 발사: 위아래 두 화면을 번갈아 볼 수 있어야 전략이 생긴다.
- 천장 타격: "벽돌을 깨면 무조건 공격"이면 조준할 이유가 없어서. 성벽을 뚫는 공간적 목표를 준다.
- 부숴도 튕김: 한 발 한 발의 각도가 중요해지도록. 대신 성벽 하강을 2턴 주기로 늦췄다.
- 질적 성장: 공격력 누적은 숫자 인플레이션과 운 의존을 만들었다. 숫자는 작게, 성장은 구슬·유물로.
- 움직이는 조준선: 피지컬(타이밍) 요소. 등속 왕복이라 어느 각도든 난이도가 같다.
