# 브릭 크롤 게임 디자인 문서 (현재 구현 기준)

> 용어: 화면에서는 본편 단위를 **층**(1층~5층), 층 안의 칸을 **방**(1~4번째 방 + 보스)이라 부른다. 이 문서와 코드의 "세션"(`RUN.s`)·"칸"(`node.r`)은 같은 뜻이다.
> 화면에 쓰는 이름(수련·공적·구슬 주머니·금화·훈장·명예의 전당·탑 입구 등)은 [`docs/GLOSSARY.md`](GLOSSARY.md)가 기준이다. 이 문서는 화면 이름을 쓰고, 필요하면 괄호에 코드 이름(`TREE`·`pts`·`deck`·`coins`·`BADGES`…)을 붙인다.

## 한 줄 요약
움직이는 조준선에 타이밍을 맞춰 구슬을 쏘고, 내려오는 성벽을 깎아 **천장에 닿게 해야** 위쪽의 몬스터를 때리는 턴제 벽돌깨기 로그라이크.

## 화면
- 위 110px: 전투(왼쪽 기사, 오른쪽 몬스터, 체력·공격·방어, 몬스터의 다음 행동 예고).
  - 몬스터 공격 예고: 머리 위 붉은 ⚔ + 숫자 = **남은 연속 공격 턴 수**. 매 턴 아래 ⚔ 숫자(공격력)만큼 때리고, 붉은 숫자는 3 → 2 → 1로 줄어든다. 예: ⚔2에 붉은 3이면 3턴 동안 2씩, 총 6.
  - 이유: 예전엔 배율(×2.5) 강공격이 있어 아래 ⚔ 숫자와 실제 피해가 어긋났다. 이제 한 번의 피해는 언제나 아래 ⚔ 숫자 그대로다.
- 아래: 벽돌판. 맨 위 굵은 선 = 천장, 중간 점선 = 붕괴선, 맨 아래 = 발사대.
- DOM: 헤더(세션·칸·이름, 금화·턴), 구슬 줄(이번 구슬 초상화 + "조준"/"발사!", 다음 구슬), 유물 칩, 오버레이(탑 입구·명예의 전당·지도·선택·일시정지).
- 전투 중 화면(2026-10-26 출시 검토): 폰 한 화면에 발사대까지 들어오게 브랜드 띠·조작 힌트를 숨기고, 헤더는 한 줄(위치 "1-5 보스"·"심연 2-3 정예" + 몬스터 이름 / 금화 그림 + "120 · 3턴" / 일시정지), 구슬 줄 높이 48px, 유물 줄은 한 줄 가로 스크롤. 판 폭은 남은 세로 높이에서 9:17로 정한다(390×844에서 330 → 364px). 긴 위치 표기("1층 · 5번째 방")는 시작 배너가 보여 준다.
- 글꼴: 화면 제목·지도 층 제목·시작 배너·시작 버튼만 픽셀 한글 Galmuri(동봉, OFL, 22·33px), 나머지는 시스템 글꼴. 작은 크기의 픽셀 글꼴은 가독성이 떨어져 되돌렸다. 선택 카드·트리 설명은 양피지 장식과 글자가 겹치지 않게 안쪽 여백을 넓혔다.
- 탑 입구(첫 화면, 코드의 메인 `ovMain`): 도트 로고, 구슬 진열, 기사 이름, 기록 줄, **시작 버튼 하나만 화려하게**(이어할 원정이 있으면 "원정 이어 가기", 없으면 새 원정: 석판 그림·크게·빛 띠·▶ 깜빡임), 심연 버튼(붉은 테 석판, 잠기면 점선), 보조 버튼(수련·도감, 얇은 테), 명예의 전당 상위 3명, 음악·효과음·테마.
- 오버레이는 위에서부터 쌓고 첫·끝 요소의 auto 여백으로 가운데 정렬한다. `justify-content:center` + 스크롤이면 넘친 위쪽(로고)이 스크롤로도 안 보이는 문제가 있었다.

## 한 턴의 흐름
1. 조준선이 일정 속도로 좌우 왕복(삼각파). 턴마다 시작 위치·방향 무작위. 시작 0.2초는 입력 무시.
   - 가속: 정예는 체력 절반 이하에서 ×1.35(배너 "정예가 날뛴다"), 보스는 페이즈마다 +30%(2페이즈 ×1.3, 최종 보스 3페이즈 ×1.6). 배너 둘째 줄은 둘 다 "조준이 빨라진다"(페이즈 번호 대신 바뀌는 규칙을 말한다). 가속 중에는 발사대 양옆에 붉은 화살표가 깜빡인다.
2. 탭/Space로 발사. 이번 구슬 하나를 쏜다(분열 구슬은 3갈래).
3. 구슬이 벽돌을 부숴도 **튕긴다**(송곳 구슬만 관통). 천장에 닿으면 몬스터 타격(구슬당 최대 3회). **피해 = 기사 공격력(⚔) + 구슬 위력(`ORB_BONUS`)** (+ 연쇄) → 비기(수련 갈래 끝, 코드의 핵심 노드) 배율. 구슬 줄에 `⚔2 + 1 = 3`처럼 식으로 뜬다(⚔ 벽돌을 깨면 왼쪽, 센 구슬이면 가운데 숫자가 오른다).
4. 구슬이 바닥에 닿으면 끝. 처음 돌아온 구슬 위치가 다음 발사 위치.
5. 몬스터 독 틱 → 몬스터 행동 → (2턴마다) 성벽 한 줄 하강 + 새 줄 → 붕괴선 넘은 벽돌은 기사에게 1개당 2 피해 → 기사 독 틱.

## 피해 규칙
- 방어도 = 체력 앞의 보호막. 피해를 먼저 흡수하고 흡수한 만큼 깎인다. 기사·몬스터 동일.
- 독 = 스택. 턴마다 스택만큼 피해(방어도 무시) 후 1 감소. 체력바 끝이 다음 틱 피해만큼 붉게 표시.
- 공격력·방어도는 전투마다 초기화(공격 1(+날 세우기), 방어 0, 갑옷·방패술만 시작 방어도). 체력은 원정 내내 이어진다(최대 24에서 시작, 보스를 잡을 때마다 +4).

## 벽돌
| 종류 | 모양 | 효과 |
|---|---|---|
| 성벽 | 회색, 숫자=내구도(1~2) | 효과 없음. 길만 막음 |
| ⚔ 공격 | 흰 바탕+칼 | 깨면 이번 전투 공격력 +1 (+수확) |
| 🛡 방어 | 흰 바탕+방패 | 방어도 +2 (+수확) |
| ♥ 체력 | 흰 바탕+하트 | 체력 +4 |
| 독 | 붉은 테두리+해골 | 깨면 기사 독 +1 |
| 돌 | 검정(보스 소환) | 내구도 3~4 |
특수 벽돌은 한 줄에 최대 1개(독은 별도 1개).

## 구슬 (구슬 주머니 = 코드의 덱, 한 턴에 하나씩, 다음 구슬 미리 표시)
구슬은 24종(등급·해금은 아래 "등급·컬렉션", 전체 목록은 `docs/tasks/03-collection.md`). 아래 표는 처음부터 있던 7종이다.
시작 주머니: 기본 2, 폭탄 1. **구슬 주머니는 최대 5개**(`DECK_MAX`). 가득 차면 보상·상인의 새 구슬은 "구슬을 바꾼다" 화면에서 가진 구슬 하나와 바꾼다(취소하면 아무것도 잃지 않고, 상인에게는 바꾼 뒤에야 값을 치른다).
구슬 위력(`ORB_BONUS`): 묵직한 +2(+는 +3), 나머지 0. 왕관 구슬의 화면 설명은 "추가 피해 = 가진 금화 ÷ 25".
구슬마다 고유 도트 스프라이트가 있고(묵직한 구슬은 더 크게), 날아가는 동안 짧은 잔상을 남긴다(독 구슬은 붉은 잔상). 벽돌에 부딪힌 순간 짧은 충격 표시가 뜬다.
| 구슬 | 효과 |
|---|---|
| 기본 | 없음 |
| 폭탄 | 처음 부순 벽돌 주변 8칸 1피해 |
| 송곳 | 아무 벽돌이나 3개까지 관통·파괴 |
| 방패 | 벽돌 파괴마다 방어도 +1 |
| 분열 | 3갈래 발사. 갈래 하나의 피해 = 전체 피해 ÷ 3(올림, 최소 1) |
| 독 | 천장 타격마다 몬스터 독 +1 |
| 묵직한 | 구슬 위력 +2 (+는 +3) |

### 등급·컬렉션
구슬 24종·유물 40종에 등급(일반·고급·희귀·전설, 가중치 60·28·10·2)이 있다(`RARITY`). 보스 보상은 유물 후보 중 희귀 1장 보장(전설 확률은 어디서나 같다). 심연은 층마다 희귀·전설 ×1.1. 상인 값도 등급으로 정한다. 일부 구슬은 훈장·심연 기록으로 해금된다(`ORBS[*].lock`). 손에 넣은 구슬·유물은 탑 입구의 **도감**에 남는다(`META.seen`). 전체 목록은 `docs/tasks/03-collection.md`.

### 구슬 강화(+)
**확률 다회 강화(+1~+5).** +1은 아래 표의 고유 효과, +2부터는 단계마다 구슬 위력 +1. 성공률은 지금 단계 기준 90/70/50/35/20%(`UP_RATE`). +3 이상에서 실패하면 한 단계 내려가고, 그 아래에서는 실패해도 그대로다. 주머니(`RUN.deck`)에는 `bomb+`(+1), `bomb+2`…로 저장한다(예전 `bomb+` 저장과 호환).
구슬 보상의 "구슬 강화" 카드 또는 상인의 "구슬 강화"(금화 30)로 주머니의 구슬 1개를 강화한다. 숫자를 키우는 대신 구슬 고유 효과를 한 단계 올린다. 주머니에는 `bomb+`처럼 저장되고, 이름 끝에 +가 붙으며 발사대 옆에 + 도트가 뜬다.
| 구슬+ | 효과 |
|---|---|
| 기본+ | 천장을 한 번 더 칠 수 있다 |
| 폭탄+ | 주변 8칸에 2씩 피해 |
| 송곳+ | 5개까지 관통 |
| 방패+ | 파괴마다 방어도 +2 |
| 분열+ | 5갈래, 피해 ÷ 5 |
| 독+ | 천장 타격마다 독 +2 |
| 묵직한+ | 구슬 위력 +3 |

## 수련 (영구 성장, 코드의 스킬 트리 `TREE`)
- 공적(코드의 포인트 `pts`): **칸을 처음 돌파할 때** +1, **세션 보스를 처음 돌파할 때** +3(`PTS`). 본편 25칸 전부 = 35점. 심연도 `abyssBest` 기준으로 같은 규칙.
- 트리 전체 비용 108점: 본편만으로는 1/3 정도. 나머지는 심연을 내려가며 채운다(다 익히기 어렵게).
- 탑 입구·"기사가 쓰러졌다" 화면에서 진입. 수련을 눌러 설명 → "익히기". 앞 수련을 익혀야 다음이 열린다("앞 수련을 먼저 익혀야 열린다"). 효과는 새 원정부터.
- 십자 4갈래(공격·방어·구슬·재물), 갈래마다 줄기 2개(2·3점) → 두 가지로 갈라져 일반 수련(3점) → **비기(8점, 마름모, 코드의 핵심 노드 `key`)**. 곱연산은 비기에만. 화면에서는 "곱연산"이라는 말 대신 "피해를 몇 배로 키운다"로 쓴다.

| 갈래 | 줄기 | 가지 A → 비기 | 가지 B → 비기 |
|---|---|---|---|
| 공격(위) | 날 세우기(기본 공격력 +1) → 연타(천장 상한 +1) | 전투 함성(⚔ 벽돌 +1) → **처형자**(절반 이하 몬스터 피해 ×1.5) | 연쇄(세 번째 타격부터 +1) → **파괴자**(피해 ×1.5) |
| 방어(아래) | 단련된 몸(최대 체력 +4) → 방패술(시작 방어도 +2) | 재생(승리 시 체력 +2) → **불굴**(받는 피해 ×0.75) | 단단한 벽(🛡 벽돌 +1) → **철벽**(얻는 방어도 ×1.5) |
| 구슬(왼쪽) | 숙련(시작 폭탄 → 폭탄+) → 눈썰미(구슬 후보 +1) | 꼼꼼한 손길(다시 살피기 +1) → **공명**(강화 구슬 피해 ×2) | 정조준(조준선 -15%) → **공성추**(묵직한·폭탄 피해 ×2) |
| 재물(오른쪽, 코드 id `e*`) | 두둑한 노잣돈(금화 +30) → 흥정(상인 -20%) | 전리품(전투 금화 +5) → **보물 사냥꾼**(유물 하나로 출발) | 약초학(모닥불·약초 +5) → **불사조**(원정마다 한 번 30%로 부활) |

## 훈장 (코드의 배지 `BADGES`, `META.badges` = { id: 받은 횟수 })
처음 받으면 화면 위에 알림("훈장 받음 · 이름") + 효과음, 다시 받으면 횟수만 오른다. 탑 입구 → 도감 화면의 훈장 구역: 받은 훈장은 실선 메달·횟수, 못 받은 훈장은 점선·?·조건을 보여 준다.

| 훈장 | 조건 |
|---|---|
| 일격 | 체력이 가득 찬 몬스터를 천장 타격 한 번으로 쓰러뜨린다 |
| 삼연타 | 구슬 하나가 천장을 딱 세 번 쳐서 가득 찬 체력을 모두 깎는다(예: 피해 3, 체력 9) |
| 탑의 정복자 | 세션 5 최종 보스 격파 |
| 무결 | 체력을 잃지 않고 보스 격파 |
| 속전속결 | 보스를 3턴 안에 격파 |
| 성벽 허물기 | 한 번 발사로 벽돌 12개 |
| 독살 / 되갚기 | 독 / 반격으로 마지막 체력을 깎는다 |
| 가벼운 짐 | 주머니에 구슬 3개 이하로 최종 보스 격파 |
| 심연의 바닥 | 심연 5층 보스 격파 |
| 거상 | 한 원정에서 금화 200개 |
| 아침 | 고난 6에서 근원 "성벽의 왕"을 쓰러뜨려 진 엔딩 |
| 독의 길 / 폭파의 길 / 저주의 길 / 방패의 길 / 갈래의 길 | 탑을 정복한 순간 주머니 구슬의 절반 이상이 그 계열(`BUILD_BADGES`) |

새 훈장은 `BADGES`에 한 줄 + 조건 자리에서 `earnBadge(id)`.

## 최종 목표: 이야기·고난 단계·근원 (작업 05)
- **왜 오르는가**: 탑에서 내려온 성벽이 마을과 동생 **하람**을 삼켰다. 매 전투에서 부수는 성벽이 바로 그 성벽이다. 첫 원정에 프롤로그(`STORY.intro`), 지도에는 층마다 하람의 흔적 한 줄(`STORY_FLOOR`).
- **첫 완주 = 결말 1 "빈 갑옷"**: 군주는 껍데기였고 탑이 다시 자란다. 하람의 목소리가 탑의 뿌리에서 들린다 → **고난 1**이 열린다.
- **고난 단계**(`ASC`, 누적): 열린 최고 단계를 깨면 다음 단계가 열리고 탑 입구에서 바로 골라진다. 탑 입구의 고난 버튼을 누를 때마다 0 → 열린 단계까지 돈다. 심연에는 걸리지 않는다.
  | 단계 | 규칙 |
  |---|---|
  | 1 날뛰는 정예 | 정예가 처음부터 분노(조준 가속) |
  | 2 무너지는 탑 | 정예도 3턴마다 벽돌 1개 낙하 |
  | 3 꺼진 모닥불 | 보스 처치 후 체력 회복 없음(최대 체력 +4만) |
  | 4 독 안개 | 모든 전투의 성벽에 독 벽돌(줄마다 25%) |
  | 5 봉인된 천장 | 보스전에서 천장 1칸 봉인 |
  | 6 근원 | 군주 격파 후 같은 체력으로 근원 "성벽의 왕" |
- **고난 조각**: 고난 1~5를 처음 깰 때마다 성벽의 왕(옛 성주)의 사연 한 조각(`STORY.a1`~`a5`).
- **근원 "성벽의 왕"**(`MON.king`, 기본 체력 30 → 5층 기준 약 43): 천장 2칸 **봉인**(빗금, 닿아도 타격 없음·타격 횟수도 안 씀). 2페이즈(체력 절반)부터 봉인이 매 턴 한 칸씩 옆으로 옮기고 다음 자리를 붉은 점선으로 예고, 3페이즈에 봉인 3칸. 전투 난수는 군주와 갈라 같은 판이 되지 않게. 군주를 잡으면 승리 회복 없이 그 체력 그대로 `RUN.king`을 저장해 새로고침해도 근원부터(`fixRun`은 고난 6·5층·보스 칸 대기일 때만 유지). 고난이 생기기 전에 완주한 계정은 고난 1이 열린 상태로 옮긴다.
- **진 엔딩 "성벽이 내려간 아침"**: 왕이 쉬고 하람과 마을이 벽돌에서 풀려난다. 심연은 "아직 숨을 쉬는" 엔딩 뒤의 도전으로 남는다.
- 본 이야기는 도감의 **이야기** 구역에서 다시 읽는다(`META.story`).

## 원정 = 5세션, 그 뒤 심연
- 본편은 **세션 5개**(`FINAL_S = 4`). 세션 5 보스는 최종 보스 "탑의 군주"(지도에 "최종"). 이기면 "탑을 정복했다" 화면 → 탑 입구. 저장은 지우고 `META.clears`를 올린다.
- **심연**: 본편을 한 번 깨면 탑 입구의 "심연으로"가 열린다(잠겼을 때 "심연 · 탑을 정복하면 열린다"). 새 주머니로 들어가는 별도 원정(`RUN.abyss`)이고 끝이 없다.
  - 몬스터: 심연 n층 = 본편 n세션 세기 × 체력 1.25^n, 공격 +n(`ABYSS`). 첫 칸부터 아무 몬스터나 나온다. 이름 앞에 "심연의".
  - 화면: `html[data-realm="abyss"]`로 테마와 무관하게 검붉은 토큰, 패널은 석판, 캔버스에 붉은 불씨·천장 균열, 머리띠·지도 제목이 붉다. 음악은 `abyss`(지도)·`deep`(전투).
  - 명예의 전당: 본편 25칸 위에 이어 센다(심연 1층 1칸 = 26).

## 원정 구조
- 지도 화면: 던전 그림을 옅게 깐 탑. 칸은 메달(전투 = 칼 도트, 정예 = 붉은 해골 도트, 모닥불(코드 `rest`) = 모닥불 그림, 상인(코드 `shop`) = 상인 그림, 보스 = 탑의 수문장)이고 이름이 아래에 붙는다. **어떤 몬스터인지는 들어가기 전까지 모른다.** 정예·보스는 붉은 테. 칸들은 아래 줄부터 차례로 떠오른다. 갈 수 있는 칸은 테두리가 진하고 통통 튄다.
- 상인·모닥불 화면 위쪽에 장면 캔버스(`js/scene.js`): 떠돌이 상인은 카운터 뒤 상인(랜턴 깜빡임)과 진열된 구슬·금화, 모닥불은 어두운 던전의 모닥불(3프레임)·불티·쉬는 기사. 동작 줄이기 설정이면 멈춘 그림.
- 세션 = 갈림길 지도 5갈래 × 4칸 + 보스(이전 3갈래 저장 지도도 그대로 그린다). 같은 칸으로는 항상, 옆 칸으로는 40% 확률로 연결.
- 지도 방: 전투(금화 10~14만, 보상 화면 없이 지도로), 정예(유물 3택1 → 구슬 보상 + 금화 22~28), 모닥불(체력 40% 회복만, 아니면 "지나가기"), 상인(구슬 2개·유물 1개는 등급별 값: 구슬 18/26/38/55, 유물 35/50/70/95. 약초 15, 강화 30, 구슬 빼기 25. 흥정 -20%, 행운 동전 -10%, 탐욕 +15. 산 물건은 "품절", 나갈 때 "떠나기"), 보스(유물 3택1 → 구슬 보상 + 최대 체력 +4 + 체력 절반 회복 + 금화 40 → 다음 층).
- 구슬 보상(구슬 3택1 또는 구슬 강화·건너뛰기·다시 살피기)은 **정예·보스 처치 때만** 나온다. 매 전투마다 주머니가 불면 구슬 하나의 무게가 가벼워져서다. 그 밖의 구슬은 상인에게서 산다.
- 첫 칸은 슬라임 고정(본편). 세션 5 보스를 이기면 탑을 정복한다.

## 몬스터 (기본값, 실제 체력 = 기본 × WALL.hpMul(0.6) × (1 + 0.35×세션), 최소 3)
패턴의 "공격 n턴" = n턴 연속으로 매 턴 공격력만큼 때린다(배율 없음). 패턴은 끝까지 가면 처음부터 반복.
| 몬스터 | 체력 | 공 | 방 | 조준선 속도 | 패턴 |
|---|---|---|---|---|---|
| 슬라임 | 6 | 1 | 0 | 0.9 | 공격 2턴, 대기 |
| 박쥐 | 8 | 1 | 0 | 1.0 | 공격 3턴, 대기 |
| 골렘 | 9 | 1 | 2 | 1.15 | 공격 2턴, 방어 +2 |
| 독버섯 | 9 | 1 | 1 | 1.3 | 공격 2턴, 독 +⚔(공격력만큼), 공격 2턴, 포자(독 벽돌 소환) |
| 탑의 수문장(1~4층 보스) | 14 | 1 | 1 | 1.4 | 공격 3턴, 돌 소환 / 체력 절반에서 2페이즈(공+1, 방+2): 공격 4턴, 돌 소환 |
| 탑의 군주(세션 5 최종) | 24 | 1 | 1 | 1.4 | 공격 2턴·돌 소환·방어 +3 / 2/3에서 2페이즈: 공격 3턴·소환 / 1/3에서 3페이즈: 공격 3턴·독 +2·소환 (페이즈마다 공+1, 방+2) |
- 보스 연속 공격 턴 수를 짧게 둔 이유: 공격력이 세션마다 +1이라 6턴이면 3세션 2페이즈 한 묶음이 4×6=24(최대 체력 전부)가 됐다.
- 세션당: 공·방 +1, 조준선 +0.1(최대 2.0). 정예: 체력 ×1.5, 방어 +1, 조준선 +0.1. (2026-10: 기본 조준 속도를 약 25% 낮추고, 정예·보스의 가속으로 긴장을 옮겼다)
- 성벽: 밀도 기본×0.5, 시작 3줄, 2턴마다 하강(소환·포자 행동 시 즉시).
- 지도 노드 가중치(2~4칸): 전투 45, 정예 10(2칸)/16, 상점 17, 휴식 18/34(4칸). 이어진 앞 칸이 휴식이면 휴식이, 상점이면 상점이 나오지 않는다(연속 금지).
- 보스 벽돌 낙하: 패턴과 별개로 3턴마다(분노 페이즈부터 2턴마다) 붕괴선 위 두 줄을 뺀 아무 칸에 벽돌 1 + ⌊깊이/2⌋개(본편 1·1·2·2·3, 심연은 층+2 기준). 이미 벽돌이 있으면 그 벽돌 체력 +1. 낙하 턴에는 행동 예고 옆에 붉은 벽돌과 개수가 뜬다. 칸별 일반 몬스터: 1칸 슬라임, 2칸 박쥐·골렘, 3칸 골렘·독버섯, 4칸 전부.

## 저장
- **2026-10-16 전체 진행도 초기화**(사용자 결정): 원정·메타 키를 v4로 올리고 옛 v2·v3 원정·메타는 옮기지 않고 지운다. 서버 랭킹도 함께 비운다(`db/migrations/0003_reset_ranking.sql`). 프로필은 키를 v2로 올려 id·닉네임·등록만 옮기고 못 보낸 옛 원정 기록은 버린다. 원정 기록에는 초기화 회차(`RESET_EPOCH` = 2)를 실어 보내고 서버는 그 회차만 받아, 초기화 전에 열어 둔 옛 버전이 지운 랭킹을 되살리지 못한다.
- `brickquest:run:v4`: 원정 전체(시드 `seed`·보상 난수 상태 `rng.reward`, 세션, 체력, 코인, 덱(강화 구슬은 `bomb+`, `bomb+2`…), 유물, 지도, 위치, 진행 중 노드, 대기 중 보상·보상 후보(`reward`), 상점 재고). 불러올 때 `fixRun()`이 깨진 값을 검사·보정한다(R02).
- `brickquest:meta:v4`: 본편 최고 칸(`best`), 심연 최고 칸(`abyssBest`), 원정 횟수, 완주 횟수(`clears`), 스킬 포인트(`pts`), 찍은 노드(`tree`), 배지(`badges`), 도감(`seen`), 열린 고난(`asc`)·고른 고난(`ascPick`)·단계별 완주(`ascClear`), 본 이야기(`story`). 고난·이야기는 필드 추가라 키 버전 유지.
  v2에서 옮길 때: 트리 노드가 새로 짜여 같은 id가 다른 효과가 됐으므로 찍은 노드는 비우고, 최고 기록으로 받을 포인트(`ptsUpTo(best)`)를 다시 계산해 준다. 예전 영혼석은 버린다. 25칸을 넘는 예전 기록(옛 심연)은 본편 완주로 본다.
- 원정 저장의 `abyss`(심연 원정)·`revived`(불사조 사용)·`pts`(이번 원정에서 받은 포인트)·`badges`는 v2 시절 추가 필드로 늘었다. 옛 출발 선물(`gift`·`giftStock`) 필드는 기능이 빠져 이어할 때 비운다.
- `brickquest:theme:v1`: 화면 테마(`auto`·`light`·`dark`).
- `brickquest:profile:v2`: 플레이어 id(비공개 UUID), 닉네임, 마지막 닉네임 변경 시각(`nameAt`), 서버 등록 여부, 아직 못 올린 원정 기록 대기열(최대 50개, 넘치면 최고 기록은 남기고 오래된 것부터 버린다).
- 원정 상태에 `rid`(원정 UUID)가 있다. 기록 서버가 같은 원정을 두 번 세지 않게 하는 용도다(없던 이전 저장은 기록할 때 새로 만든다).
- 저장 시점: 노드 진입, 전투 승리, 보상 선택, 상점 구매, 강화 결과. 전투 도중 상태는 저장하지 않는다. 이어하면 그 전투를 처음부터 하되, 전투 난수가 칸마다 정해져 있어 같은 벽돌·덱 순서·첫 조준으로 시작한다(R06).

## 사운드 (`js/audio.js`, Web Audio 합성)
- BGM: `calm`(탑 입구·지도·모닥불·상인·보상, 84bpm 가단조, 드럼 없음), `battle`(일반·정예 전투, 132bpm), `boss`(보스전, 150bpm 라단조, 톱니파 베이스), `abyss`(심연 지도, 66bpm 반음 진행), `deep`(심연 전투, 112bpm 단2도 리프). 패배하면 음악을 멈추고 패배 음을 낸다.
- 구슬별 소리: 벽돌 충돌은 파형·높이가 구슬마다 다르다(송곳=톱니 "지직", 독=물방울, 묵직한=낮은 쿵, 방패=맑은 금속). 같은 구슬의 연속 충돌은 반음씩 올라간다(최대 한 옥타브). 천장 타격은 가장 밝고 큰 상승 화음이고, 같은 구슬의 2·3번째 타격은 더 높다.
- 그 밖: 발사, 돌(둔탁), 폭탄 폭발, 몬스터 피격(3 이상이면 묵직하게)·쓰러짐, 기사 피격·방어, 강화 벽돌 도착(공·방·체·독), 성벽 하강·붕괴, 보스 등장·분노, 승리·패배, 상인 입장·구매, 모닥불 입장·회복, 카드 고르기.
- 같은 소리가 몰리면(분열·폭탄) 이름별 최소 간격(약 30ms)으로 거른다. 마지막에 압축기를 둬 겹쳐도 찢어지지 않게 한다.
- 설정 `brickquest:audio:v1`: `{ bgm, sfx }`. 기본은 둘 다 켬. 탭이 숨으면 소리를 멈춘다.

## 기사 이름·명예의 전당 (코드의 닉네임·랭킹·기록 서버)
- 기사 이름(코드의 닉네임) = 맛·감각 꾸밈말 + 성격 꾸밈말 + 중세 판타지 사물, 모두 3음절(47×48×70 ≈ 15만 가지. 사물은 쇠사슬·양피지처럼 기사의 세계에 있을 법한 것만). 탑 입구에 처음 들어올 때 임의로 정해지고, 이후 탑 입구의 "변경"으로 **일주일에 한 번** 직접 입력한 닉네임으로 바꿀 수 있다(한글·영문·숫자·공백 2~12자, 앞뒤·연속 공백 없음, 중복 불가, **금지어 불가**: 욕설·성적·혐오 표현·운영자 사칭. 소문자로 바꾸고 공백·숫자를 지운 뒤, 영문을 뺀 꼴·한글을 뺀 꼴까지 부분 문자열로 찾아 "시1발"·"f u c k"·"시a발" 같은 우회도 거른다. 목록 `BAD_NAME`은 서버와 `js/profile.js`가 같고 회귀 검사가 둘이 같은지, 자동 닉네임이 하나도 걸리지 않는지 확인한다). 형식·중복·7일 제한은 서버(`POST /api/rename`, `players.name_at`)가 최종 판정하고, 동시에 두 번 보내도 한 번만 바뀐다. 오프라인이면 바꿀 수 없다("인터넷에 연결해야 바꿀 수 있다"). 서버에서 이름이 겹치면 시스템이 다시 뽑는다.
- 원정이 끝날 때(쓰러짐·포기·저장된 원정 덮어쓰기·완주) 그 원정의 도달 칸 수(`세션×5 + 마지막으로 완료한 칸`, 심연은 +25)를 올린다. 서버는 플레이어별 최고 기록을 유지한다. 원정 시작과 지도 화면마다 원정 시작 표(`/api/start`)를 보낸다. 서버는 시작 표를 받은 뒤 칸당 5초 이상 지난 기록만 그대로 명예의 전당에 쓰고, 그 밖(오프라인에서 시작·옛 버전·너무 빠름)은 5칸까지만 반영한다(위조 비용 올리기. 모든 API에 속도 제한).
- 개인정보(2026-10-26): 탑 입구 맨 아래 `개인정보 처리방침`(privacy.html)·`내 기록 삭제`(버튼 "명예의 전당 기록 지우기"를 두 번 눌러 확정 → `/api/delete`로 서버의 기사 이름·원정 기록·시작 표 삭제, 기기에는 새 id·새 기사 이름. 진행도는 남는다).
- 명예의 전당: 최고 기록 내림차순, 같으면 먼저 세운 쪽이 위. 탑 입구에 상위 3명 + 내 줄, 명예의 전당 화면에 상위 10명 + 내 줄. 불러오지 못하면 "명예의 전당을 불러오지 못했다". 내 줄은 반전 색. 1위도 붉게 칠하지 않는다(붉은색 = 위험).

## 설계 원칙 (지금까지의 결정과 이유)
- 실시간 패들 대신 턴제 조준 발사: 위아래 두 화면을 번갈아 볼 수 있어야 전략이 생긴다.
- 천장 타격: "벽돌을 깨면 무조건 공격"이면 조준할 이유가 없어서. 성벽을 뚫는 공간적 목표를 준다.
- 부숴도 튕김: 한 발 한 발의 각도가 중요해지도록. 대신 성벽 하강을 2턴 주기로 늦췄다.
- 질적 성장: 공격력 누적은 숫자 인플레이션과 운 의존을 만들었다. 숫자는 작게, 성장은 구슬·유물로.
- 움직이는 조준선: 피지컬(타이밍) 요소. 등속 왕복이라 어느 각도든 난이도가 같다.
