# 더미 그림 목록 ("마지막 번개")

시나리오 "마지막 번개"(`docs/SCENARIO.md`)에 필요한 그림 중 아직 없는 것을 **더미**로 채워 두었다.
더미는 `python3 tools/make_dummy_assets.py`가 만든다(회색 실루엣 + 영문 이름 + "DUMMY").
진짜 그림은 **같은 파일 이름**으로 `assets/game/`에 넣으면 코드 수정 없이 바로 바뀐다. 이미 있는 파일은 도구가 덮어쓰지 않는다(`--force`만 덮어씀).

- 전투 그림은 동작 시트(`이름_actions.png`, 6열 × 3줄: 공격·피격·쓰러짐)를 더하면 기존 인물처럼 움직인다. 없으면 한 장 그림에 숨쉬기만 한다(`js/art.js` `drawCharArt`). 시트를 더하면 `ART_SHEET`에 대기 포즈 크기(`iw`·`ih`)를 적는다.
- 그림이 없거나 못 읽으면 전투는 예전 그림(`knight`·`boss`) → 도트 순서로 대신 그린다. 초상은 없으면 이름만 보인다.
- 일러스트 위 색은 테마와 무관한 고정색이다(다크 모드는 배경을 덮어 맞춘다).

## 소리
장면 효과음(`cup_drop`·`jog_tick`·`radio_static`…)은 Web Audio 합성으로 들어가 있다(`js/audio.js` `SFX`). 층별 BGM(대본 5장 BGM_03~13)은 아직 기존 곡(`calm`·`battle`·`boss`)을 쓴다. 음원을 더하면 `TRACKS`에 등록하고 `assets/audio/LICENSE.md`에 권리를 적는다.
