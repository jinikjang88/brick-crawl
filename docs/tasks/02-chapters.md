# 작업 02: 최종 5세션 + 챕터 구조 (기록만, 아직 구현하지 않음)

## 배경 (2026-10 결정)
- 원정 한 판(챕터)은 **최종 5세션**으로 끝난다. 5세션 보스가 챕터의 최종 보스.
- 챕터를 깨면 **다음 챕터**로 넘어가고, 챕터마다 **다른 몬스터 종류**(새 스프라이트·패턴)가 나온다.
- 엔드게임 랭킹은 "얼마나 깊이 내려갔는가". 스킬 트리 핵심 노드(곱연산)가 깊이 내려가는 수단이다.

## 지금 상태 (시험판)
- 3세션 이후를 **무한 심연**으로 둔다(`js/data.js`의 `ABYSS_FROM = 3`). 층마다 몬스터 체력 ×1.3, 공격 +1.
- 지도 제목·헤더는 `stageName(s)`: 본편은 "세션 N", 심연은 "심연 N층".
- 랭킹 기록은 그대로 `세션×5 + 칸`(심연 층이 깊을수록 높다).

## 구현할 때 정할 것
- 챕터 1(지금 몬스터) 5세션 구성: 세션 4·5의 칸 구성과 보스(작업 01의 "성벽의 왕"을 챕터 1 최종 보스로 쓸지).
- 챕터 2 이후 몬스터 목록·패턴, 필요한 일러스트(assets/illustrated에 원본 추가 → tools/build_game_assets.py).
- 무한 심연을 챕터 구조 안에서 어디에 둘지(마지막 챕터 뒤, 또는 각 챕터의 도전 모드).
- 랭킹 단위: `챕터×25 + 세션×5 + 칸` 등으로 바꾸면 서버 `MAX_PROGRESS`와 기존 기록 비교를 함께 고친다.
- 저장 구조가 바뀌면 `v`를 올리고 이전 저장을 옮긴다(AGENTS.md).
