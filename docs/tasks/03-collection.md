# 작업 03 — 구슬·유물 컬렉션 (구현 완료)

> 원정 보상에는 곱연산을 두지 않는다(AGENTS.md). 초안의 ×2·×3 효과는 덧셈으로 바꿔 구현했다.

목표: 구슬·유물을 "모으는" 재미. 등급과 등장 확률을 두고, 일부 구슬은 조건을 만족해야 해금된다.
숫자 인플레이션 금지 원칙은 유지한다: 효과는 전투마다 초기화되거나 질적(규칙을 바꾸는) 효과다.

## 1. 등급과 확률 (구슬·유물 공통)
| 등급 | 표시 | 가중치 | 상점 가격(구슬/유물) | 비고 |
|---|---|---|---|---|
| 기본 | — | 0 | — | 시작 덱 전용(기본 구슬) |
| 일반 | 무채(ink3) | 60 | 18 / 35 | |
| 고급 | 진한 무채(ink) | 28 | 26 / 50 | |
| 희귀 | 화색 테두리 | 10 | 38 / 70 | 붉은색 = 희귀 등급(UI 규칙 유지) |
| 전설 | 화색 채움 | 2 | 55 / 95 | 보스 보상에서만 가중치 ×3 |

- 보스 보상의 유물 후보 3장 중 1장은 희귀 이상을 보장한다.
- 심연에서는 층마다 희귀·전설 가중치 +10%(곱)로 깊이 내려갈 이유를 준다.
- 강화(+1~+5, 확률)는 모든 구슬에 같은 규칙으로 적용한다(작업 A·B에서 구현 완료).

## 2. 구슬 (7 → 24종)
`*` = 기존. **디버프** = 몬스터를 약하게 하는 구슬(요청 10). 🔒 = 해금 조건 필요(요청 12).

| 등급 | 이름 | 효과 | 강화(+1) |
|---|---|---|---|
| 기본 | 기본 구슬* | 효과 없음 | 천장 타격 상한 +1 |
| 일반 | 폭탄 구슬* | 처음 부순 벽돌 주변 8칸 피해 1 | 주변 피해 2 |
| 일반 | 송곳 구슬* | 벽돌 3개 관통 | 5개 관통 |
| 일반 | 방패 구슬* | 벽돌 파괴마다 방어도 +1 | +2 |
| 일반 | 탄력 구슬 | 이 구슬만 천장 타격 상한 +1 | +2 |
| 일반 | 약초 구슬 | 처음 천장을 칠 때 체력 +1 | +2 |
| 일반 | 가시 구슬 | 벽돌 3개를 부술 때마다 몬스터에게 1 피해 | 2개마다 |
| 고급 | **약화 구슬** | 디버프: 천장 타격 시 몬스터의 남은 연속 공격 −1 (최소 1, 발사당 1회) | 발사당 2회 |
| 고급 | **무장해제 구슬** | 디버프: 천장 타격 시 이번 전투 몬스터 ⚔ −1 (최소 1, 전투당 2회) | 전투당 3회 |
| 고급 | **부식 구슬** | 디버프: 천장 타격 시 몬스터 방어도를 0으로 | + 다음 수비 행동 무효 |
| 고급 | 자석 구슬 | 바닥에 닿으면 한 번 다시 튀어 오른다 | 두 번 |
| 고급 | 망치 구슬 | 돌 벽돌(보스 소환)에 피해 3 | 피해 5 |
| 희귀 | 분열 구슬* | 3갈래, 피해 ÷3 | 5갈래, 피해 ÷5 |
| 희귀 | 독 구슬* | 천장 타격마다 독 +1 | +2 |
| 희귀 | 묵직한 구슬* | 피해 보정 +2 | +3 |
| 희귀 | 사슬 구슬 | 같은 발사 안에서 천장 타격마다 피해 +1 누적 | +2 누적 |
| 희귀 | **기절 구슬** | 디버프: 천장을 3번 치면 몬스터가 다음 행동을 건너뛴다(전투당 1회) | 2번 |
| 희귀 | 흡혈 구슬 | 천장 타격 2번마다 체력 +1 | 매번 |
| 전설 | 혜성 구슬 🔒 | 모든 벽돌 관통, 천장 타격 1회, 피해 보정 +4 | 보정 +6 |
| 전설 | **시간 구슬** 🔒 | 디버프: 몬스터 패턴을 첫 행동으로 되돌리고 연속 공격 −2 | 전투당 2회 |
| 전설 | 왕관 구슬 🔒 | 피해 보정 = 가진 코인 ÷ 25 | ÷ 15 |
| 희귀 | 맹독 구슬 🔒 | 천장 타격마다 독 +1, 몬스터 독이 줄어들지 않음 | 독 +2 |
| 희귀 | 거울 구슬 🔒 | 이번 턴 몬스터 공격의 절반을 되돌림 | 전부 |
| 희귀 | 철거 구슬 🔒 | 마지막 천장 타격 피해 + 이번 발사에 부순 벽돌 수 ÷ 3 | ÷ 2 |

## 4. 화면
- 메인 화면에 **도감**(구슬·유물·배지) 버튼. 본 적 있는 것은 그림과 설명, 못 본 것은 실루엣, 잠긴 구슬은 해금 조건을 보여 준다.
- 카드 테두리로 등급을 구분한다(희귀·전설만 화색). 새 구슬 그림은 도트 문양으로 먼저 만들고, 일러스트(png)는 이후 작업.

## 5. 저장
- 메타에 `seen:{orb:{}, relic:{}}`(도감) 추가. 해금은 배지·심연 기록에서 바로 계산해 따로 저장하지 않는다. 필드만 늘었고 예전 메타도 빈 도감으로 읽히므로 키 버전은 그대로(`meta:v3`).

## 6. 검증
- 시뮬레이터 봇은 보상 첫 카드를 고르므로, 등급 확률 분포가 의도대로인지 뽑기 1만 회 통계를 따로 찍는다.
- 1세션 돌파율 30~40%, 보스 격파 시 체력 중앙값 20~30% 유지.
