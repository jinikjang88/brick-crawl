# 06. 출시 전 코드 리뷰 (2026-10-26)

출시(₩1,000, Google Play·App Store) 전에 전체 코드를 리뷰했다.

- 범위: `index.html`, `css/style.css`, `js/*.js`, `functions/api/[[path]].js`, `db/schema.sql`, 그리고 테스트 도구가 현재 코드와 맞는지.
- 결론: **P0(즉시 막아야 할 보안 사고)는 없다.**
  - 랭킹 닉네임은 모두 `textContent`로 넣는다. 저장소에 `innerHTML`·`eval`은 없다.
  - SQL은 모두 바인딩으로 넣는다.
  - 비밀 플레이어 id는 POST 본문에만 싣는다.

## 기획 판단이 필요한 것
- **전투 도중 이탈.** 메뉴의 "메인 화면"으로 나가면 지금 전투가 처음부터 다시 시작된다(메뉴 안내문에도 적혀 있다). 지기 직전에 나가면 사실상 되돌리기가 된다. 선택지는 둘이다.
  - (a) 지금처럼 허용한다.
  - (b) 전투 중 이탈에 체력 페널티를 준다.
