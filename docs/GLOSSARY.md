# 용어집 (Ubiquitous Language)

브릭 크롤의 **화면에 보이는 말**은 이 파일 하나가 기준이다. 화면 문구(DOM·토스트·배너·aria-label·데이터의 `name`·`desc`), `privacy.html`, 문서(README·GAME_DESIGN)는 모두 여기의 "화면 이름"을 쓴다.

- 새 UI 문구는 이 표의 화면 이름만 쓴다. 표에 없는 새 개념이면 **이 파일에 먼저 한 줄을 올리고** 코드에 쓴다.
- 코드 식별자·객체 키·DOM id·CSS 클래스·저장 키(`deck`·`coins`·`badges`·`pts`·`tree`·`brickquest:*`)는 바꾸지 않는다. 화면 이름과 코드 이름이 다른 것은 의도다(저장 호환·서버 API 유지). 코드 주석에서는 개발 용어를 써도 된다.
- 한 개념에는 화면 이름 하나. 같은 화면 안에서 짧게 줄일 때만 "짧은 꼴"을 쓴다.

## 세계관 (2026-10-30 이야기 "마지막 번개", 대본 `docs/SCENARIO.md`)

OMNIS가 하늘을 쇠창살 패널로 닫은 세계. 15살 **릭**이 몸이 굳어 가는 동생 **리나**의 치료 기록을 찾아, 박사가 남긴 쇠구슬과 MP3를 들고 데이터 골짜기 맨 아래 제로 코어까지 **내려간다**.
(2026-10-28의 디지털 던전 이야기 "디버거·하람·화요일의 알고리즘"은 이 이야기로 바뀌었다. 데이터 벽·버그·크레딧 같은 사물 이름은 그대로 쓴다.)
화면의 말은 **개발자의 말(IT 용어)**로 고른다. 버그·칩·크레딧·커밋처럼 세계 안의 사물로 쓰는 말은 허용하고, 게임 시스템 자체를 가리키는 말(스킬 트리·포인트·덱·코인·랭킹·메인 화면·노드)은 화면에 내보내지 않는다.

예전 중세 이름(기사·탑·성벽·금화·훈장…)은 "쓰지 않는 말"이 되었다. 이름을 바꿀 때는 받침이 달라져 조사가 바뀌는 말을 함께 고친다(탑을 → 서버를, 금화가 → 크레딧이, 훈장을 → 트로피를, 상인이 → 브로커가, 모닥불을 → 충전소를, 심연을 → 심층부를).

## 바꾸지 않는 말(정본)

이름을 바꾸지 않은 핵심 어휘도 이 표가 기준이다. 같은 개념을 다른 말로 새로 쓰지 않는다.

| 개념 | 화면 이름 | 코드 이름 | 쓰지 않는 말 |
|---|---|---|---|
| 한 판 | 접속 | `RUN` | 판, 게임, 런, 원정 |
| 쏘는 것 | 구슬 | `ORBS`, `RUN.deck` 원소 | 공, 볼 |
| 깨는 것 | 벽돌 | 벽돌판 격자 | 블록(칩 이름 "블록 빌더"만 예외) |
| 영구 장비 | 칩 | `RELICS`, `RUN.relics` | 아이템, 렐릭, 유물 |

## 말투 규칙

| 자리 | 꼴 | 예 |
|---|---|---|
| 라벨·버튼·제목 | **명사** 또는 **-기** 꼴 | 모듈, 떠돌이 브로커, 지나가기, 떠나기, 설치하기 (커밋 3), 다시 스캔하기 (1회) |
| 상태·결과 메시지(토스트·결과 제목·안내) | **해라체** 평서문 | OMNIS를 멈췄다, 연결이 끊겼다, 순위표를 불러오지 못했다, 앞 모듈을 먼저 설치해야 열린다 |
| 권유·다시 시도 | **~해 보자** | 첫 접속을 시작해 보자, 잠시 뒤 다시 해 보자 |
| 알림 토스트 | `무엇 · 값` | 트로피 받음 · 고래, 커밋 +1 · 첫 돌파, 호출명 변경 · …, 구슬 해금 · 폭탄 구슬 |

## 바꿀 때

1. 이 표의 화면 이름을 먼저 고친다.
2. `index.html`, `js/*.js`의 문자열, `privacy.html`, README·GAME_DESIGN을 함께 고친다(한 곳만 바꾸면 같은 개념이 두 이름이 된다).
3. `tools/regress.mjs`가 화면 문구를 정규식으로 보는 곳(예: `/인터넷에 연결/`)을 맞춘다.
4. 큰 제목(`.big`, Galmuri 33px · 좁은 화면 22px)은 360×640에서 한 줄에 들어가는지 확인한다.
- "쓰지 않는 말"을 고치면 `tools/regress.mjs`의 화면 용어 검사(`BANNED`)도 함께 고친다. 회귀 검사가 화면 문구에 쓰지 않는 말이 다시 들어오는지 확인한다.
