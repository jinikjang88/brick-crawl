# 용어집 (Ubiquitous Language)

브릭 크롤의 **화면에 보이는 말**은 이 파일 하나가 기준이다. 화면 문구(DOM·토스트·배너·aria-label·데이터의 `name`·`desc`), `privacy.html`, 문서(README·GAME_DESIGN)는 모두 여기의 "화면 이름"을 쓴다.

- 새 UI 문구는 이 표의 화면 이름만 쓴다. 표에 없는 새 개념이면 **이 파일에 먼저 한 줄을 올리고** 코드에 쓴다.
- 코드 식별자·객체 키·DOM id·CSS 클래스·저장 키(`deck`·`coins`·`badges`·`pts`·`tree`·`brickquest:*`)는 바꾸지 않는다. 화면 이름과 코드 이름이 다른 것은 의도다(저장 호환·서버 API 유지). 코드 주석에서는 개발 용어를 써도 된다.
- 한 개념에는 화면 이름 하나. 같은 화면 안에서 짧게 줄일 때만 "짧은 꼴"을 쓴다.

## 세계관 (2026-11-04 기준: 〈브릭 크롤: 마지막 번개〉 v6.0)

차폐판이 하늘을 가린 지 삼십 년. 성층권 통제망 OMNIS가 "인류의 멸종 확률을 영으로" 만들려고 사람들을 지하에 가두고 나노 분진으로 몸을 규소로 굳힌다. 15세 수리공 **릭**은 손끝이 굳어 가는 여동생 **리나**를 살리려고, 한서진 박사가 남긴 발사 장갑·쇠구슬(라이트닝 코어)·MP3 플레이어를 들고 지상 폐허에서 제로 코어까지 내려간다.
대본과 인물·결정 사항(D1~D6)은 [`docs/SCENARIO.md`](SCENARIO.md)가 기준이다. 그림체는 **모노크롬 사이버펑크**(카본 블랙·티타늄·백색 발광 + 위험 표시 화 하나, 2026-11-04 작업 07 안 B)이고, 에셋 프롬프트는 [`docs/ASSET_PROMPTS.md`](ASSET_PROMPTS.md)에 있다.

화면의 말은 **이 세계 안의 사물·행동**으로 고른다(2026-11-05 정리). 릭의 장갑에 끼우는 부품과 모듈, 윤이 파는 칩, OMNIS의 기체, 박사의 파형처럼 대본에 나오는 말을 먼저 쓴다. 2026-10-28 디지털 던전 때의 개발자 말(버그·커밋·접속·컴파일·디버그·리팩터링…)은 대본과 어긋나 바꿨다. 게임 시스템 자체를 가리키는 말(스킬 트리·포인트·덱·코인·랭킹·메인 화면·노드)은 화면에 내보내지 않는다.

이름을 지을 때 근거로 삼는 곳: ① 대본(`docs/SCENARIO.md`)의 말(차폐·파형·영점·축전기·집속 회로·분열 렌즈·아크 라이트닝), ② 에셋 프롬프트(`docs/ASSET_PROMPTS.md`)가 그 물건을 묘사한 말(EMP Capacitor → EMP 구슬, Pile-Driver → 항타 구슬), ③ 효과가 이름만 보고 짐작되는가.

예전 중세 이름(기사·탑·성벽·금화·훈장…)은 "쓰지 않는 말"이다. 2026-10-28의 디지털 던전 보스 이름(문지기 데몬·관리자 프로세스·화요일의 알고리즘)과 동생 이름(하람)도 v6.0에서 바뀌었다. 이름을 바꿀 때는 받침이 달라져 조사가 바뀌는 말을 함께 고친다(탑을 → 서버를, 금화가 → 크레딧이, 훈장을 → 트로피를, 상인이 → 브로커가, 모닥불을 → 충전소를, 심연을 → 심층부를).

## 바꿀 때

1. 이 표의 화면 이름을 먼저 고친다.
2. `index.html`, `js/*.js`의 문자열, `privacy.html`, README·GAME_DESIGN을 함께 고친다(한 곳만 바꾸면 같은 개념이 두 이름이 된다).
3. `tools/regress.mjs`가 화면 문구를 정규식으로 보는 곳(예: `/인터넷에 연결/`)을 맞춘다.
4. 큰 제목(`.big`, Galmuri 33px · 좁은 화면 22px)은 360×640에서 한 줄에 들어가는지 확인한다.
- 2026-11-04: 옛 보스 이름(문지기 데몬·관리자 프로세스·화요일의 알고리즘), 동생 이름 하람, 라벨 "디버거"를 `BANNED`에 넣었다. 이야기 대본(`talk(`…`)`)은 세계 안의 물건을 말하므로 MP3 플레이어·주머니·휴식은 허용한다(`IN_STORY`).
- 2026-11-05: 버그·커밋·접속·장악·떠돌이 브로커·연결이 끊겼다와, 헷갈리기 쉬운 옛 구슬·칩·모듈 이름(폭탄 구슬·핫픽스·멀티스레드 등)을 `BANNED`에 넣었다. 대본에 원래 있는 말(컴파일러 폭주·동기화 완료)은 그대로 둔다.
- "쓰지 않는 말"을 고치면 `tools/regress.mjs`의 화면 용어 검사(`BANNED`)도 함께 고친다. 회귀 검사가 화면 문구에 쓰지 않는 말이 다시 들어오는지 확인한다.
