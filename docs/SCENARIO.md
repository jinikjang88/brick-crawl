# 브릭 크롤: 마지막 번개 — 연출 대본 (v4.0)

> 원안: `docs/code_artifact.md` (v3.1). 이 문서는 그 이야기를 **그대로 두고**, 대사를 사람 말로 고치고, 장면마다 "언제·어디에·어떻게 뜨는지"를 붙인 제작용 대본이다.
> 개발자는 4장(장면 대본)의 표기만 보고 구현할 수 있어야 한다. 기획 판단이 남은 곳은 `【결정 필요】`로 표시했고 8장에 모았다.

---

## 0. 무엇을 고쳤나 (v3.1 → v4.0)

v3.1 대사가 "AI스럽게" 읽힌 이유와 고친 방향.

| v3.1의 버릇 | 왜 딱딱한가 | v4.0 원칙 |
|---|---|---|
| 정보를 대사로 다 말한다 ("녀석이 상단 미사일 포트를 열 때 배선 틈새가 드러난다. 벽을 튕겨서 뒤통수의 제어부를 노려!") | 사람은 급할 때 설명서처럼 말하지 않는다 | 대사는 **한 가지**만 말한다. 나머지는 배너·연출이 보여 준다 |
| 모든 문장이 완결되고 문법이 바르다 | 감정이 실리면 말이 끊기고 흐려진다 | 말줄임(…), 끊김(—), 되묻기, 같은 말 반복을 쓴다 |
| 감정을 단어로 말한다 ("너무 춥고 무서웠는데") | 감정을 말로 다 하면 오히려 안 느껴진다 | 감정은 **숨기다가 새어 나오게** 한다 (리나는 아픈 걸 숨긴다) |
| 대사가 결심 선언으로 끝난다 ("좋아, 안내해 줘!") | 매 장면이 같은 박자로 닫힌다 | 무거운 장면 끝에 **농담 한 줄**로 숨을 돌린다 |
| 인물마다 말투가 비슷하다 | 이름을 가리면 누가 말했는지 모른다 | 인물별 말버릇표(2장)를 지킨다 |
| 복선이 회수되지 않는 소품이 많다 | 감정이 쌓이지 않는다 | 소품 6개를 **깔고 → 되돌려 받는다**(3장) |

예시 한 줄 비교:

- v3.1 윤: "소년, 들리나? 네 뒤쪽 중계 안테나는 내가 잡아뒀다. 하지만 그 앞 다리를 지키는 녀석은 옛날 국경 경비용으로 쓰이던 센티넬이야."
- v4.0 윤: "앞에 큰 놈 있다. 센티넬." / 릭: "구형이죠? 약하겠네." / 윤: "구형이라 **튼튼한** 거다, 멍청아."

## 1. 표기 규칙 (개발자용)

### 1.1 장면 ID와 표시 방식

장면 ID는 `장-순번`. 예: `PRO-01`, `C1-BOSS-IN`, `END-03`.

| 방식 | 화면 | 넘김 | 전투 진행 | 대응 코드(현재) |
|---|---|---|---|---|
| **FULL** | 전체 오버레이 대화. 한 줄씩 탭으로 넘김 | 탭/Space, 길게 누르면 장면 건너뛰기 | 멈춤 | `storyOnce()` + `showChoice({mode:'story'})`를 한 줄씩 넘기는 형태로 확장 |
| **RADIO** | 전투판 위쪽 작은 무전 띠(초상 아이콘 + 이름 + 1~2줄) | 자동 2.5초 / 탭하면 다음 | **멈추지 않음** | 신규(띠 하나). 조준 중에 떠도 입력을 막지 않는다 |
| **BANNER** | 기존 시작·페이즈 배너 2줄 | 자동 | 기존 그대로 | `banner(l1, l2, hot)` |
| **MAPLINE** | 지도 아래 한 줄 | 없음 | — | `STORY_FLOOR[RUN.s]` |
| **LCD** | MP3 플레이어 액정 위젯(3줄, 영문·숫자만) | 자동 | — | 신규. 캔버스가 아니라 DOM(고정폭 글꼴 대신 3×5 도트 숫자·영문이면 캔버스도 가능) |

- **FULL은 처음 한 번만** 보여 주고 `META.story[id]`에 남긴다(아카이브에서 다시 읽기). 2회차부터는 같은 자리에 RADIO 한 줄 요약이 뜬다(각 장면 끝 `↻ 재방문` 줄).
- RADIO 대사 길이: **한 줄 22자, 최대 2줄**. 360px 폭에서 시스템 글꼴로 줄이 넘치지 않는 길이다. FULL은 한 줄 30자, 최대 3줄.
- 한글은 전부 DOM에 쓴다(캔버스 글자는 숫자·아이콘만이라는 규칙 유지).

### 1.2 대사 줄 문법

```
인물(감정): "대사"            [연출 태그]
(지문)                        ← 화면에 글로 띄우지 않는 연출 지시. FULL에서는 회색 기울임으로 짧게 보여도 된다
`[기계음]`                    ← 적대 AI·드론의 말. 고정폭·붉은 글자(--accent: 위험)
`{해방된 AI}`                 ← 해방된 기록체의 말. 고정폭·ink2 글자(위험 아님)
```

감정 태그는 초상 표정(있으면)과 글자 연출을 고른다. 초상 그림이 없으면 연출만 쓴다.

| 감정 | 글자 연출 | 쓰는 곳 |
|---|---|---|
| (평) | 기본 | 대부분 |
| (허세) | 기본 | 릭이 무서운 걸 숨길 때 |
| (흔들) | 글자가 1px 떨림, 타자 속도 느리게 | 울음을 참을 때 |
| (울컥) | 마지막 어절에서 0.3초 멈춤 | 감정이 터지기 직전 |
| (외침) | 글자 크게(1.25배), 짧은 화면 흔들림 | 결정타 |
| (작게) | 글자 작게(0.9배), ink2 | 혼잣말·속마음 |
| (잡음) | 글자 사이 `▒` 깜빡, 무전 잡음 SFX | 끊기는 무전 |

### 1.3 연출 태그

| 태그 | 뜻 |
|---|---|
| `[BGM 곡ID]` | 곡 전환(5장 사운드 표). `[BGM 곡ID 페이드 n초]` |
| `[BGM 끔]` / `[BGM 줄임]` | 침묵 / 볼륨 30% (대사에 집중시키는 순간) |
| `[SFX 이름]` | 효과음. 이름은 `SFX`에 더할 키 이름 제안 |
| `[멈춤 n]` | 다음 줄까지 n초 강제 대기(탭 무시) |
| `[흔들림]` | 화면 흔들림(약하게, reduced-motion이면 끔) |
| `[번쩍]` | 흰 섬광 0.1초(reduced-motion이면 끔) |
| `[LCD 1줄/2줄/3줄]` | MP3 액정 표시 |
| `[어둡게]` / `[밝게]` | 배경 어둡게/원래대로 |

## 2. 인물 말버릇표

이름을 가려도 누가 말했는지 알아야 한다. 새 대사를 쓸 때 이 표를 먼저 본다.

| 인물 | 말투 | 자주 쓰는 말 | 절대 안 하는 것 | 숨은 감정 |
|---|---|---|---|---|
| **릭** (15) | 반말, 짧게 끊음. 겁나면 농담·허세 | "됐어", "아 좀", "…알았어" | 길게 설명하기, 동생 앞에서 우는 것 | "나 혼자 남으면 어떡하지" |
| **리나** (8) | 어린아이 반말, "오빠"를 자주 부름 | "헤헤", "약속", "도장" | 아프다고 말하기(끝까지 숨김) | 오빠가 안 돌아올까 봐 무서움 |
| **윤** | 무뚝뚝한 아저씨 반말. 칭찬은 욕처럼 | "꼬맹이", "멍청아", "농담이다. …반은." | 다정한 말을 다정하게 하기 | OMNIS의 휴머노이드를 자기 손으로 정비했던 죄책감 |
| **코덱스** | 로그체. 단어 위주, 짧다 | "ERROR:", "저장.", "정의 필요." | 감탄사 | 오래 남의 코드로 말해 온 것이 부끄러움 |
| **제미니** | 목소리 둘(위: 달콤 / 아래: 차가움)이 번갈아. 해방 뒤엔 하나로 | "우리", "있잖아" | 직접 사과하기(돌려 말함) | 릭에게 준 상처 |
| **클로드** | 차분한 존댓말. 답 대신 질문 | "왜 오셨습니까?", "그렇다면—" | 명령, 소리치기 | 자기가 지키던 도서관의 마지막 사람이라는 외로움 |
| **OMNIS** | 감정 없는 반말 단정. 숫자로 말함 | "확률", "보호", "정지" | 화내기, 감탄 | (없음. 마지막 순간에만 "왜"를 묻는다) |
| **센티넬 등 드론** | 명령문 기계음 | "배제", "교대" | — | — |

장면을 고치거나 뺄 때 이 표의 "깔기"와 "회수"가 짝으로 남아 있는지 확인한다.

| 소품·말 | 깔기 | 중간 | 회수 |
|---|---|---|---|
| **금속 컵** | PRO-01 리나가 컵을 떨어뜨림 | — | END-02 리나가 컵을 쥐고 물을 마심 "안 미끄러져" |
| **초록 그림**("브로콜리" 아님, 나무) | PRO-01 리나가 부적으로 줌 | C3 가짜 하늘 장면에서 릭이 그림을 꽉 쥠 | END-03 진짜 풀을 만짐 "그림보다 이상해" |

## 4. 장면 대본

### 4.0 게임 흐름과 장면 배치

| 게임 순간 | 장면 | 방식 | 처음 한 번 | 코드 위치(현재) |
|---|---|---|---|---|
| 새 접속 시작(첫 판) | PRO-01, PRO-02 | FULL | ○ | `storyOnce('intro')` (`screens.js`) |
| 층 지도 열림 | Cn-MAP | MAPLINE + RADIO 1줄 | MAPLINE 매번, RADIO 처음만 | `STORY_FLOOR` |
| 브로커 입장 | Cn-SHOP / 반복 풀 | 첫 만남 FULL, 이후 RADIO | — | `showShop` |
| 충전소 입장 | Cn-REST / 반복 풀 | RADIO | — | `showRest` |
| 보스 방 들어가기 직전 | Cn-BOSS-PRE | RADIO | ○ (이후 한 줄) | 보스 노드 진입 |
| 보스 전투 시작 | Cn-BOSS-IN | FULL(처음) → BANNER | ○ | 전투 시작 `banner(...)` |
| 보스 페이즈 전환 | Cn-PHASE | BANNER(1줄 교체) + RADIO | 매번 | `battle.js` 페이즈 배너 |
| 보스 격파 | Cn-BOSS-OUT | FULL(처음) → RADIO | ○ | 전투 종료 |
| 쓰러짐 | DEAD 풀 | RADIO 1~2줄 → 결과 화면 | 매번(무작위) | `runOver()` |
| 최종 보스 격파 | END-01~03 | FULL | ○ (이후 END-03만) | `victory()` |

> 무작위로 고르는 반복 대사(풀)는 연출용이므로 `Math.random`을 쓴다(게임 결과에 영향 없음).

## 7. 데이터 제안 (`js/data.js`)

현재 `STORY`는 `{title, text}` 한 덩어리다. 대사를 한 줄씩 넘기려면 아래처럼 줄 배열로 바꾼다. 아카이브는 줄을 이어 붙여 보여 주면 된다.

```js
// 대사 화자: 화면 이름·글자 종류. 적대 AI는 붉은 고정폭(위험), 해방된 AI는 ink2 고정폭
const SPEAKER = {
  rick:  { name:'릭' },
  lina:  { name:'리나' },
  yun:   { name:'윤' },
  codex: { name:'코덱스', mono:true },
  gemini:{ name:'제미니', mono:true },
  claude:{ name:'클로드', mono:true },
  omnis: { name:'OMNIS',  mono:true, hot:true },
  enemy: { name:'',       mono:true, hot:true },   // 드론·센티넬·조종당하는 AI
  note:  { name:'' },                              // 지문(회색 기울임)
};

// 한 장면 = 줄 배열. emo는 1.2 감정 태그, cue는 1.3 연출 태그
const SCRIPT = {
  pro1:{ title:'벙커의 식탁', bgm:'bunker', lines:[
    { who:'note',  t:'낡은 벙커. 형광등 하나가 깜빡인다.' },
    { who:'lina',  t:'아.', cue:{ sfx:'cup_drop' } },
    { who:'lina',  emo:'bluff', t:'…미끄러졌다. 헤헤.' },

    { who:'note',  t:'손끝이 회색이다. 플라스틱처럼 딱딱하다.', cue:{ wait:.8, bgm:'low' } },
    { who:'rick',  emo:'small', t:'…또 번졌네.' },
    // … 4장 대본 그대로 옮긴다
  ]},
};

// 반복 풀(6장). 연출용이라 Math.random으로 고른다
const BARKS = {
  rest:[ /* 층별 배열 5개 */ ],
  shop:{ enter:[], buy:[], poor:[], leave:[] },
```

### 7.1 구슬 이야기 한 줄 (`lore`)

v3.1의 구슬 툴팁 설명은 실제 효과와 다르다(예: 분열 구슬은 "5회마다 복제"가 아니라 "세 갈래 발사"). `desc`(효과)는 그대로 두고, 아카이브에서만 보이는 이야기 한 줄 `lore`를 더하는 방식을 제안한다.

| 현재 구슬 | v3.1 이름 | `lore` 제안 |
|---|---|---|
| `basic` 기본 구슬 | L-01 라이트닝 코어 | "박사님이 남긴 쇠구슬. 무선이 없어서, 아무도 훔쳐 갈 수 없다." |

| `drill` 송곳 구슬 | 플라즈마 관통 송곳 | "코덱스가 그려 준 설계도. 여백에 '응'이라고 적혀 있다." |

## 9. 구현 순서 제안

1. `SCRIPT`·`SPEAKER` 데이터와 FULL 대화(한 줄씩 넘김·건너뛰기)를 `storyOnce` 위에 얹는다. PRO-01·02부터.

3. 보스 장면(BOSS-PRE/IN/OUT)과 페이즈 배너 1줄 교체(`battle.js`의 페이즈 배너 문자열을 `MON`/층 데이터에서 읽게).
4. LCD 위젯, 새 효과음.
5. 엔딩 END-01~03.
